# OVERTURE: A Free Game Music Sampler: file manifest

67 of the 68 `.ogg` files carry LOOPSTART and LOOPLENGTH loop tags in the file.

Every file is byte for byte the file of the same name that is already free on its own album page (`album.json` in the download lists the sha256 of every `.ogg` and `.mid` and the free zip it came from).
