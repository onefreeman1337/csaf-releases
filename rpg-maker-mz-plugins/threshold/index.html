Threshold - Animated Doors From Your Own Tileset for RPG Maker MZ is an RPG Maker MZ plugin for RPG Maker, paid.

Every door in your own tileset opens the way it was drawn. Threshold is a plugin for RPG Maker MZ. In stock MZ an opening door needs a hand drawn character sheet (the!Door style) for every door you use, and a custom tileset usually has none, so its doors just vanish. Threshold reads the door tile you already placed, once, when the map loads, and draws its opening from that tile's own pixels.

Give a tile event one note, <threshold: door>, and it opens. Your existing door events already work. The stock Door quick event opens a door by turning it left, right, then up.

Threshold reads those turns as the stages of its opening, so every door event you have animates your tile with no edits. ⚠️ Compatibility — the question you actually have Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order: ThresholdCore.js — Threshold core: derives door opening frames from your own tile pixels. Load BEFORE Threshold. Threshold.js — Threshold: every door, gate, hatch and cave mouth in your own tileset opens the way it was drawn.
