Verdict Core - Investigation, Cross-Examination & Deduction for RPG Maker MV & MZ is an RPG Maker MZ plugin for RPG Maker, paid.

Keep your clue system. This is the part where the player has to be right. Every clue plugin for RPG Maker MZ tracks what the player has found. None of them resolves a piece of evidence against a claim. Verdict Core does — and it answers with three results, not two. Now for RPG Maker MV as well as MZ.

The same two plugin files run in MV 1.6 with one more file from the download, CSAF_MVBridge.js, placed at the top of the Plugin Manager. In MV each command is a Plugin Command line such as VerdictCore giveExhibit exhibitId=bloodied_glove; the guide lists every one. Every command and all four scenes were run on both engines from the shipped zip, and the bridge does nothing at all in MZ.

New in 1.2: every verb works with a finger or a mouse. Tap a statement to select it and tap it again to press it. The PRESENT tab presents an exhibit, tap two cards on the board to run the string, tap a blank to fill it, and COMMIT commits the accusation. Keyboard and gamepad work exactly as before. The tabs follow MZ's own Touch UI option, and RPG Maker MV gets the same paper tabs, CLOSE included.
