Majora’s Mask. Outer Wilds. Deathloop. 12 Minutes. The mechanic is easy to describe and miserable to hand-roll — because a time loop is not really about time. It is about bookkeeping: what snaps back, what survives, what the game must remember that the world has forgotten, and how the player is ever shown any of it.

Loop Core is that bookkeeping, plus the screen that makes it legible. ⚠️ Compatibility — the question you actually have Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests. Plugin Manager order: LoopCore.js — The time-loop engine. The world resets, the player does not. Anchors, rewinds, carried knowledge and loop-gated events.

LoopLedger.js — The Loop Ledger scene. Every loop a ring, every divergence a pin, everything known a constellation. LoopRewind.js — The rewind. A full-screen time-collapse shader that plays while the world snaps back to the anchor. LoopCore is required; LoopLedger and LoopRewind are optional and can be switched off without breaking the loop.
