Living Icons - Animated Menu Icons for RPG Maker MZ (glint, twinkle, bubble, flicker, pulse) is an RPG Maker MZ plugin for RPG Maker, paid.

Its title or description names RPG Maker MZ.

Every icon in your menus moves by what it is. Blades glint, gems twinkle, potions bubble, fire flickers with embers, key items pulse. Living Icons reads your database to decide which effect each icon gets and reads the icon's own pixels to decide where the light goes, so there are no frames to draw and nothing to tag. Restrained on purpose.

Each icon plays briefly and then rests, and identical icons in one list move out of step, so a full inventory shimmers instead of strobing. Greyed entries stay greyed.

It works in every window that draws icons: items, skills, equipment, shops, status. ⚠️ Compatibility — the question you actually have Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.
