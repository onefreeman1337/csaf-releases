Herbarium is 4 RPG Maker MZ plugins that draw a botanical plate for every herb, root and fungus from that item's own data. Royalty free in commercial games.

What is inside 4 plugin files · 5 plugin commands · 97 motifs across 10 axes · 8 ink colours · no image files, every plate drawn at runtime The plate: the humour picks the ink, the preparation cuts the leaf margin, the potency decides the root, and the part your recipes use goes in the fragment packet The note tag: write <herbarium: moonwort> on an item and it has a plate.

Blank fields are derived from the key, so a key draws the same plate on every save and machine The study record: a gathered specimen starts as an unnamed sketch, then gains its name and reading, then its straps, packet and wax seal The cabinet: one scene the plugin draws itself, a wall of plates beside an enlarged sheet, set in two font stacks you can change in the Plugin Manager Inventory marks: a collected specimen's icon becomes its own small mark, per item, with a parameter to turn it off Event hooks: a switch for a finished plate and a variable for the count, so a reward can depend on them Sixteen specimens from one plugin.
