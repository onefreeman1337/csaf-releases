Bazaar Core is a free RPG Maker MZ plugin with 9 commands: finite shop stock, prices set by supply and demand, and price gaps between towns.

What is inside 1 core plugin · 1 market screen plugin · 9 plugin commands · 21 parameters · 109 automated tests Finite stock: buy twenty and there are twenty fewer, and an empty shelf refills over days on a restock curve you set Prices worked out from stock against demand every time, so a price never drifts out of step with the shelf Each town keeps its own stock and demand, so the same good costs different money in different places Trade routes: the market screen shows where a good is cheapest and dearest, and what each unit earns between them One notetag per item, <bazaar: iron_ore>, and the stock MZ shop keeps working; items without it behave as before Commodities, markets, shortage and glut multipliers, sell margin and a price ceiling, all set in the Plugin Manager Nothing in that gap is scripted.

Supply and demand in each town produced both prices. Works with Tested against RPG Maker MZ with the stock scripts unmodified, by running the plugin in the engine. Plugin Manager order: BazaarCore.js, then BazaarMarketUI.js.
