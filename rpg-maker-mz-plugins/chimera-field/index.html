Chimera Field is a 3 plugin set for RPG Maker MZ creature games: spawn tables per biome, rarity tiers, level bands, variant rates and a Field Guide. Royalty free in commercial games.

What is inside 3 plugin files · 4 plugin commands · 1 Field Guide scene · raw JavaScript source Biome spawn tables: one table per biome, filled in once in the Plugin Manager, with species, rarity and level band per row Rarity tiers: you write rare instead of a weight, and one tier list rebalances every biome at once Level bands per biome: the same species can be a level 3 nuisance in the meadow and a level 30 threat in the cavern Time, weather and switch gates: night only, rain only, or hidden until a switch flips.

A gate stays open when your game supplies no such information, so a project with no day and night plugin still gets encounters Variant rates: a 1 in N shiny roll, recorded permanently in the guide One map, many biomes: region IDs override the map's biome, so a shore, a wood and a cave can share one overworld Fight one species repeatedly and its variant odds improve, clamped so a variant is never guaranteed.
