Aperture Core is a 3 plugin photo mode for RPG Maker MZ: the player frames a shot, racks focus and presses the shutter, and the engine scores the print. Name your own price, including free.

What is inside 3 plugin files · 6 plugin commands · 1 viewfinder scene · 1 album scene · raw JavaScript source A real viewfinder: rule of thirds guides that fade while you move, autofocus brackets that name the subject, and a live grade from F to S Depth of field: a gaussian blur over the world, driven by how far the focal plane sits from the subject Six aperture stops: f/1.8 to f/11, with a bar that narrows as the aperture opens Focus peaking: in focus edges painted in a hot colour by a GLSL shader.

If a driver refuses the shader, the camera carries on without it An album of developed prints: each print is about 900 bytes of save data, redrawn in 16 colours every time it is shown.

Sixty photographs cost roughly 55 KB Photo requests: a commission completes the moment a good enough print is filed, and your events read the result into a switch One notetag to set up: <photo: forest_wolf, Grey Wolf, size=1.6, rarity=3, points=180> in any event's note box The field album.
