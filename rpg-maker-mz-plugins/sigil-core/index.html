Sigil Core - Procedural Spell Seals & Magic Circle Generator for RPG Maker MV & MZ is an RPG Maker MZ plugin for RPG Maker, paid.

This plugin does not report on your spells. It draws them. Add a skill to your database and its magic circle already exists — a unique, animated, hand-drawn-looking seal generated from that skill’s own data. You never open an art program. You never commission a seal. You never draw the twenty-third one. Now for RPG Maker MV as well as MZ.

The same three plugin files run in MV 1.6 with one more file from the download, CSAF_MVBridge.js, placed at the top of the Plugin Manager; in MV the Grimoire opens with the Plugin Command line SigilGrimoire open. Every parameter in the guide, the script calls and the Grimoire were run on both engines from the shipped zip, and every seal comes out the same figure on both. The bridge does nothing at all in MZ.
