Chronicle Core is a quest plugin for RPG Maker MZ with 12 commands: branching outcomes that close each other off, faction reputation and world state. The download holds three raw, commented JavaScript plugin files, a Readme, a licence and a four tab journal scene. Every quest reads one world state, so a choice in one quest can move another.

Use it in any number of free or commercial games with no royalties; the plugin files may not be resold. It works beside the quest log you already use. What is in it World state: named flags and counters, one store per save, which every quest can read. A choice in Act 1 moves a quest written in Act 3 without either quest knowing the other exists.

Committed branches: taking one branch permanently closes the others in that quest, and taking a closed branch raises an error, so both sides can never be set at once. Faction reputation: integer standing with named tiers and an event each time a tier is crossed. Objectives that read the world, hidden objectives included, and quest failure as a latching state of its own.

The Chronicle: a record of every choice in order, with the standing it moved and the consequence you wrote.
