What this is, in plain words: Chronicle Core is a quest consequence plugin for RPG Maker MZ (version 1.0, tested on the stock MZ scripts). The download holds three JavaScript plugin files (raw, readable source), a Readme and a licence.

It adds branching quest outcomes, choices that close off other paths, faction reputation on a signed scale, and named world state your events can check, driven by 12 plugin commands, plus a journal scene. It works beside the quest log you already use. Licence: use it in any number of free or commercial games with no royalties; the plugin file itself may not be resold. There is no free version.

Your quest plugin remembers what the player was told. Nothing remembers what they did. There are seventeen quest plugins for RPG Maker MZ. Every one of them is a journal — a place to read back what an NPC already said. Not one of them decides what happens when the player picks a side. So you build it yourself, out of switches. Switch 41 is "sided with the thieves". Switch 42 is "sided with the merchants".
