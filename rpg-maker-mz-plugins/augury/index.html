Your game already has a fortune-teller. This is the deck she reads from. Augury generates a complete 78-card arcana — 22 trumps and four suits of fourteen — from 46 hand-authored motifs, drawn as vector geometry while your game runs. Nothing ships as an image file. The package is six JavaScript files plus one bridge file for MV, a Readme and a licence: 78 KB, no atlas, no icon sheet, no PNG. Then it deals with them.

NEW IN 2.1 — RPG Maker MV, and three fixes Augury now runs in RPG Maker MV 1.6 as well as MZ. The same six files, with one bridge file (CSAF_MVBridge.js, in the download) at the top of MV’s Plugin Manager. In MV each command is a Plugin Command line, for example Augury read spread=three question="What waits at Vantre?"; the guide lists all nine.

Every command and parameter in the guide was run on both engines from the shipped download: 173 checks, and the same seed deals the same cards on MZ and on MV.

Fixed in 2.1: Bind the last reading now binds the reading the player just saw (in 2.0 it found nothing); a pact outcome that lands as a battle ends now runs its common event on the map in MZ; a misspelt spread name is reported in the console instead of dealing one card.
