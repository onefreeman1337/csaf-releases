Escapement - Generated Clockwork Gear Puzzles for RPG Maker MZ is an RPG Maker MZ plugin for RPG Maker, paid.

A locked door in RPG Maker is usually a switch and a line of text. Escapement turns it into a mechanism the player has to finish: a brass plate with fixed arbors, a tray of loose wheels, a mainspring that drives, and a payoff that only moves when the train is right. Every puzzle is generated from a seed and laid around a working train, so it cannot be unsolvable. The same event always gets the same puzzle.

Nothing is loaded from an image file: every wheel, plate, jewel, dial and bolt is drawn in code. Add one plugin command to an event. Pick a grade and what the train drives.

The event waits while the player works, then carries on with your switch already set. ⚠️ Compatibility — the question you actually have Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.
