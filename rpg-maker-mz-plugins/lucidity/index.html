Lucidity is 3 RPG Maker MZ plugins for horror games: one sanity value, 5 tiers it falls through, and 44 apparitions drawn by code as it falls. Royalty free in commercial games.

What is inside 3 plugins · 5 plugin commands · 44 apparition motifs in 7 families · 5 tiers · no image files, every mark drawn at runtime The director: one value from 100 (clear headed) to 0, eroded by map drains, region drains, items and skills Event variants: a page comment such as <Lucidity Tier: 2+> makes that event page exist only inside that band, so the frightened shopkeeper you wrote appears when the player is frightened Apparitions: figures, watchers, false doors, stains, writing, wrong light and doubles, placed the same way per save, map and tier, so a haunted room stays haunted Afflictions: each tier can apply a state to the party and fire a common event once on entry The Psyche scene: the player's own read out, a seal generated from the record, with the latest causes named Mirror variable: point it at your own stress or morale variable and Lucidity runs off that instead All 44 apparitions, drawn by the plugin at runtime in the current tier's colours.
