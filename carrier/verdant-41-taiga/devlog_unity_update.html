Verdant 41 Taiga now opens in Unity. The download has a new folder, importers/Unity/. Copy it into your project's Assets, run one menu command (Tools > CSAF Verdant > Verdant 41 Taiga > Build Unity Assets), and it builds everything inside your own project. If you already own the pack, download it again to get it. csaf.itch.io/verdant-41-taiga

What the command makes: the sheets set to pixel exact import (Point filter, 16 pixels per unit, no compression), 345 named sprites, 345 Tiles with collision where the ground or an object blocks, one RuleTile brush for each of the six transition sets, Tile Palettes, and a scene that rebuilds the sample map, The Frozen River.

The RuleTiles come straight from how the pack was drawn. Every transition tile in a Verdant set is drawn for one pattern of its eight neighbours, so each tile became one rule. Paint a bog into the forest floor and the edges and corners pick themselves.

How it was checked: we installed the folder into a subfolder of a blank Unity 6000.5.7f1 project and ran the command twice. Every RuleTile was painted in all 256 possible neighbourhoods and drew the right tile each time (1,536 of 1,536). Unity's render of the sample scene matched our sample map pixel for pixel (221,184 pixels, 0 different). A second project without the 2D Tilemap Extras package still built everything except the brushes and said how to add them. The command was run in batch mode; the editor window was not opened.

Every tile is drawn by our own procedural pixel art engine, which is AI written software. No image model, no scraped art and no training data.
