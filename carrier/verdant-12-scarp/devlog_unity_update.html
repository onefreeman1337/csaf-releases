Verdant 12 Scarp now opens in Unity. The download has a new folder, importers/Unity/. Copy it into your project's Assets, run one menu command (Tools > CSAF Verdant > Verdant 12 Scarp > Build Unity Assets), and it builds everything inside your own project. If you already own the pack, download it again to get it. csaf.itch.io/verdant-12-scarp

What the command makes: the sheets set to pixel exact import, 414 named sprites, 414 Tiles, 7 RuleTile brushes (the upland and its scarp, the talus, the track on both levels, the bracken on both levels, and the edge where this meadow meets Verdant 01's grass), Tile Palettes, and a scene that rebuilds the sample map.

The elevation brush is the reason this pack exists, and it is the one that benefits most. Every transition tile in a Verdant set is drawn for one pattern of its eight neighbours, so each became one rule: paint a plateau any shape and the rock face, the lit lip and the cast shadow land where they belong.

How it was checked: we installed the folder into a subfolder of a blank Unity 6000.5.7f1 project and ran the command twice. Every RuleTile was painted in all 256 possible neighbourhoods and drew the right tile each time (1,792 of 1,792). Unity's render of the sample scene matched our sample map pixel for pixel (153,600 pixels, 0 different). The command was run in batch mode; the editor window was not opened. While repackaging we also corrected the Tiled version the Readme and the importer board quote: it is 1.12.2.

Every tile is drawn by our own procedural pixel art engine, which is AI written software. No image model, no scraped art and no training data.
