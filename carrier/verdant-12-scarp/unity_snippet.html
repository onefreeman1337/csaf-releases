Unity

New: a Unity layer. Copy importers/Unity/Verdant12Scarp/ into your project and run one menu command (Tools > CSAF Verdant > Verdant 12 Scarp > Build Unity Assets). It sets every sheet to pixel-exact import, slices 414 named sprites and builds 414 Tiles, 7 RuleTile brushes, 12 Tile Palettes and a scene with the sample map. Paint the upland with its brush and the scarp face, the lit lip and the shadow choose themselves.

Tested in a blank Unity 6000.5.7f1 project with the folder in a subfolder and the command run twice: every RuleTile drew the right tile in all 256 neighbour arrangements (1,792 of 1,792), every sprite matched the shipped sheets texel for texel, and Unity's render of the sample scene matched our map pixel for pixel (153,600 px). The brushes need the free 2D Tilemap Extras package; without it everything else still builds. No collision is set, because this pack declares no passability. The command was run in batch mode; the editor window was not opened.
