Verdant 20 Prison now opens in Unity. The download has a new folder, importers/Unity/. Copy it into your project's Assets, run one menu command (Tools > CSAF Verdant > Verdant 20 Prison Tileset for RPG Maker MZ, Tiled & Godot Cellblock, Bars & Exercise Yard [16x16] > Build Unity Assets), and it builds everything inside your own project. If you already own the pack, download it again to get it. csaf.itch.io/verdant-20-prison

What the command makes: the sheets set to pixel exact import, 750 named sprites and Tiles, 12 RuleTile brushes, 6 AnimatedTiles, 18 Tile Palettes, and a scene that rebuilds the sample map, the cell wing and the exercise yard beyond its wall.

Each transition set is now one brush: paint a breeze block cell wall, a run of bars, the landing grating, the outer brick wall or the yard track, any shape, and the edges and corners choose themselves. The sweeping searchlight and the failing strip light play as AnimatedTiles.

How it was checked: we installed the folder into a subfolder of a blank Unity 6000.5.7f1 project and ran the command in batch mode. Every RuleTile was painted in all 256 possible neighbourhoods and drew the right tile each time (3,072 of 3,072). Every sprite matched the shipped sheets texel for texel, and Unity's render of the sample scene matched our sample map pixel for pixel (239,616 pixels, 0 different). The editor window was not opened. The download now holds 898 files.

One correction on the page while we were there. It used to say the two animations were declared for Tiled and Godot. They are not: in the Tiled, Godot and RPG Maker MZ importers every frame is its own tile, and the frame order is in tiles.json. Unity is the first engine folder in this pack that plays them. The page now says so.

Every tile is drawn by our own procedural pixel art engine, which is AI written software. No image model draws any tile; the cover illustration on the page is made with one, and the listing carries the Generative AI tag.
