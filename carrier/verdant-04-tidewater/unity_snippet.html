Unity

New: a Unity layer. Copy importers/Unity/Verdant04Tidewater/ into your project and run one menu command (Tools > CSAF Verdant > Verdant 04 Tidewater > Build Unity Assets). It sets every sheet to pixel-exact import, slices 771 named sprites and builds 771 Tiles, 9 RuleTile brushes, 6 AnimatedTiles and 21 Tile Palettes. Paint with a brush and the shoreline picks its own edges and corners.

The surf, the reef edge and the river animate in Unity, and the river runs as a true loop (0, 1, 2, never backwards), the one thing RPG Maker MZ's water slot cannot do for it. The speed is MZ's own water speed, half a second a frame, because this pack declares no timing of its own.

Tested in a blank Unity 6000.5.7f1 project with the folder in a subfolder and the command run twice: every RuleTile was painted in all 256 neighbour arrangements and drew the right tile (2,304 of 2,304), every sprite matched the shipped sheets texel for texel, and Unity read every animation back with its frames in order. The brushes need the free 2D Tilemap Extras package; without it everything else still builds. No collision is set (this pack declares no passability), and the sample map is not rebuilt as a Unity scene because it borrows 13 tiles from Verdant 01. The command was run in batch mode; the editor window was not opened.
