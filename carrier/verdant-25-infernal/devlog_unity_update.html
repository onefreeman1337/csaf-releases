Verdant 25 Infernal now opens in Unity. The download has a new folder, importers/Unity/. Copy it into your project's Assets, run one menu command (Tools > CSAF Verdant > Verdant 25 Infernal Tileset for RPG Maker MZ, Tiled & Godot Lava, Basalt, Ash & Brimstone [16x16] > Build Unity Assets), and it builds everything inside your own project. If you already own the pack, download it again to get it. csaf.itch.io/verdant-25-infernal

What the command makes: the sheets set to pixel exact import, 848 named sprites and Tiles, 12 RuleTile brushes, 25 AnimatedTiles, 17 Tile Palettes, and a scene that rebuilds the sample map, the sulphur works above the lava channel.

Each transition set is now one brush: paint a lava channel, a basalt wall, an ash drift or a sulphur flat, any shape, and the edges and corners choose themselves. The brazier, the lava fall, the geyser, the fumarole and the rest play as AnimatedTiles at RPG Maker MZ's own tile rate, 500 ms a frame, because the pack declares no timing of its own.

How it was checked: we installed the folder into a subfolder of a blank Unity 6000.5.7f1 project and ran the command in batch mode. Every RuleTile was painted in all 256 possible neighbourhoods and drew the right tile each time (3,072 of 3,072). Every sprite matched the shipped sheets texel for texel, and Unity's render of the sample scene matched our sample map pixel for pixel (239,616 pixels, 0 different). The editor window was not opened. The download now holds 976 files.

Every tile is drawn by our own procedural pixel art engine, which is AI written software. No image model draws any tile; the cover illustration on the page is made with one, and the listing carries the Generative AI tag.
