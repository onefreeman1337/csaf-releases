Verdant Side East: Feudal Village, Mountain Temple and Bamboo Forest is now in Verdant Library: 719 side view platformer tiles at 16x16 for three biomes, a feudal village (239 tiles), a mountain temple (252) and a bamboo forest (228). It carries 9 autotile sets of 47 shapes each (6 solid ground sets and 3 back walls), 60 slope pieces at 45 and 22.5 degrees, 47 kinds of object (6 animated), three parallax layers for each biome and a finished sample level for each, all in one locked 115 colour palette. It ships importers for Tiled and Godot 4. It is the fourth side view volume in the library, on the same 16x16 grid as Verdant Side, Verdant Side Depths and Verdant Side Village.

It is new here first. Verdant Side East has no page of its own yet, so this library is the first place it ships. Its folder, side-view/verdant-side-east-village-temple-bamboo/, holds 943 files: the finished, tested package its own page will carry, copied file for file and checked against that package's manifest.
