Verdant Weather: Animated Weather Overlays is now in Verdant Library: 43 animated weather overlays for 16x16 maps in Tiled and Godot 4, in 10 families: rain (10), snow and sleet (6), fog and mist (5), cloud shadows (2), light shafts (3), leaves and petals (5), embers and ash (2), glows, motes and spores (6), sand (2), and underwater (2). That is 600 animation images in 5,248 tile files, painted on a layer above your map. RPG Maker MZ is not offered for this pack, because MZ animates only its A1 water.

It is new here first. Verdant Weather has no page of its own yet, so this library is the first place it ships. Its folder, weather-overlays/verdant-weather-overlays/, holds 5,425 files: the finished, tested package its own page will carry, copied file for file and checked against that package's manifest.

If you already own the library, download it again at no extra cost and the new folder is there. That makes 101 packs on this page, 67,439 tiles in all.

Changelog, version 1.7.0: added Verdant Weather. Before this build went up, the test report was brought current for all 101 packs: the tile proof ran again on every tile pack, every importer reference was resolved again from its library folder, the new pack was installed fresh into blank projects while the others keep their earlier fresh install results, matched to unchanged files, and every count in the Readme and catalogue was derived again from the files.
