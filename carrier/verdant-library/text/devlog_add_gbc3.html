Verdant GBC 3: Elemental Dungeons Tileset is now in Verdant Library: 919 Game Boy Color tiles at 16x16, across four elemental dungeons built on one shared puzzle kit, each in a lit and a dark palette that differ by colour alone. It has 16 terrain sets, 77 objects and 9 animated pieces, and 8 GB Studio backgrounds ready to import, lit and dark, each with its .mono.png. The tiles split as The Sand Temple 230, The Ice Palace 228, The Fire Keep 233, and The Sunken Shrine 228.

It is new here first. Verdant GBC 3 has no page of its own yet, so this library is the first place it ships. Its folder, handheld-palette/verdant-gbc-03-elemental-dungeons/, holds 2,212 files: the finished, tested package its own page will carry, copied file for file and checked against that package's manifest.

If you already own the library, download it again at no extra cost and the new folder is there. That makes 102 packs on this page, 68,358 tiles in all.

Changelog, version 1.8.0: added Verdant GBC 3. Before this build went up, the test report was brought current for all 102 packs: the tile proof ran again on every tile pack, every importer reference was resolved again from its library folder, the new pack was installed fresh into blank projects while the others keep their earlier fresh install results, matched to unchanged files, and every count in the Readme and catalogue was derived again from the files.

New to the series? The Verdant 00 Series Sampler is free, so you can try the style in your engine first. If the Library helps your game, a quick rating is the best way to support it and keeps the free packs coming.
