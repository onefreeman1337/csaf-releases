Verdant Library now holds 97 packs. The new one is Verdant Breeze: Animated Grass and Trees Tileset: 3,780 animated 16x16 meadow tiles in 8 terrain sets, where a crest of wind travels across the field instead of the whole field pulsing together. The wave rolls in Tiled and Godot 4, Unity gets brushes that pulse, and RPG Maker MZ gets still pages.

It is new here first. Verdant Breeze has no page of its own yet, so this library is the first place it ships. Its folder, top-down-16px/verdant-breeze/, holds the finished, tested package that its own page will carry, copied file for file, with every file checked against that package's manifest. When its own page opens, this folder is taken again from that page's build.

Before this build went up, the library's full test report was run again over all 97 packs: the tile proof on every tile pack (the battle backgrounds are whole images with no grid), every importer reference resolved from its library folder, a fresh install into blank projects, and every count in the Readme and catalogue derived again from the files. The whole library now carries 59,844 tiles and 850 autotile sets.

If you already own the library, the new build is on the same page now. The list price stays $19.99.
