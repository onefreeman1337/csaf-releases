Verdant GBC 2: Coast, Forest, Port, Tower Tileset is now in Verdant Library: 1,067 Game Boy Color tiles at 16x16, 18 terrain sets, 79 objects and 8 animated objects, in four seasons and a night palette that differ by colour alone. The Coast has 237 tiles, the Forest 225, the Mountain 226, the Port 201 and the Tower 178.

It is new here first. Verdant GBC 2 has no page of its own yet, so this library is the first place it ships. Its folder, handheld-palette/verdant-gbc-02-coast-forest-mountain-port-tower/, holds 6,272 files: the finished, tested package its own page will carry, copied file for file and checked against that package's manifest.

If you already own the library, download it again at no extra cost and the new folder is there. That makes 100 packs on this page, 62,191 tiles in all.

Changelog, version 1.6.0: added Verdant GBC 2. Before this build went up, the full test report ran again over all 100 packs: the tile proof on every tile pack, every importer reference resolved from its library folder, a fresh install into blank projects, and every count in the Readme and catalogue derived again from the files.
