Verdant GBC Far Lands is now in Verdant Library: 1,197 Game Boy Color tiles at 16x16 in five regions, the Ancient Ruins (293 tiles), the Desert Kingdom (256), the Eastern Village (243), the Mire (226) and the Graveyard (179). It carries 20 autotile sets of 47 shapes each, 65 objects (11 animated pieces), 10 sample scenes and day, dusk and night palettes that differ by colour alone, with 30 backgrounds ready for GB Studio colour mode. It ships importers for GB Studio, Tiled, Godot 4 and RPG Maker MZ. It is the eighth Game Boy palette volume in the library, on the same 16x16 grid as Verdant GB and the six earlier Verdant GBC volumes.

It is new here first. Verdant GBC Far Lands has no page of its own yet, so this library is the first place it ships. Its folder, handheld-palette/verdant-gbc-far-lands-ruins-desert-eastern-village-mire-graveyard/, holds 4,173 files: the finished, tested package its own page will carry, copied file for file and checked against that package's manifest.

If you already own the library, download it again at no extra cost and the new folder is there. That makes 109 packs on this page, 72,837 tiles in all.
