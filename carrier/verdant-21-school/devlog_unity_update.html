Verdant 21 School now opens in Unity. The download has a new folder, importers/Unity/. Copy it into your project's Assets, run one menu command (Tools > CSAF Verdant > Verdant 21 School Tileset for RPG Maker MZ, Tiled & Godot Classroom, Corridor, Gym & Yard [16x16] > Build Unity Assets), and it builds everything inside your own project. If you already own the pack, download it again to get it. csaf.itch.io/verdant-21-school

What the command makes: the sheets set to pixel exact import, 783 named sprites and Tiles, 12 RuleTile brushes, 8 AnimatedTiles, 17 Tile Palettes, and a scene that rebuilds the sample school with its hall, library, corridor, classrooms and yard.

Each transition set is now one brush: paint a classroom floor, a corridor wall, a display board, a blackboard or the yard's wetpour, any shape, and the edges and corners choose themselves. The classroom fish tank and the yard flagpole play as AnimatedTiles in their declared frame order.

How it was checked: we installed the folder into a subfolder of a blank Unity 6000.5.7f1 project and ran the command twice. Every RuleTile was painted in all 256 possible neighbourhoods and drew the right tile each time (3,072 of 3,072). Every sprite matched the shipped sheets texel for texel, and Unity's render of the sample scene matched our sample map pixel for pixel (239,616 pixels, 0 different). The command was run in batch mode; the editor window was not opened. We also corrected the Tiled version the listing, the Readme and the importer board named: it is 1.12.2, the version we actually measured.

Every tile is drawn by our own procedural pixel art engine, which is AI written software. No image model draws any tile; the cover illustration on the page is made with one, and the listing carries the Generative AI tag.
