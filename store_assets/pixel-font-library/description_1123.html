What every face contains

A glyph sheet PNG in white ink on transparency (your engine tints it), an AngelCode BMFont .fnt with kerning, a TrueType .ttf that draws the same pixels as the sheet, and a metrics JSON for a custom renderer: 5,123 glyphs and 800 kerning pairs across the 21 faces. Every pair face covers printable ASCII, Latin 1 accents for the main European languages and six typographic marks. Slate Type adds Latin Extended A and Cyrillic for 33 languages; Codex Type and Phone Line's message faces cover ASCII and Latin 1; Phone Line's status face is capitals, digits and punctuation and its clock face is digits and clock marks. The families also carry a ready Godot font file per face, a Godot demo project, and files for GameMaker, Ren'Py and RPG Maker MZ. Each pack sits in its own folder with its own Readme and licence.

Compatibility: tested in Godot 4.7.2 from the bytes of this download, where every glyph of every face drew pixel for pixel the same as its sheet. Any engine that loads a TrueType font or reads BMFont can use them. Use whole number sizes with smoothing and hinting off; the Readme gives the Godot import settings.
