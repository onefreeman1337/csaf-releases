Two original pixel fonts drawn as a pair for horror games. Sallow is the dialogue face: a narrow hand for notes, diary pages, dialogue, item text and menus that stays readable over a whole page (native 14 px). Shroud is the display face: tall condensed letters with cut tops and drips for title screens, chapter cards, location names and the word on the wall (native 22 px). White ink on a transparent background, so your engine tints them to any colour.

What is in the download

  • Sallow/ and Shroud/: the glyph sheet (.png), an AngelCode BMFont file (.fnt, kerning included), a TrueType file (.ttf) that draws the same pixels, and a metrics JSON for a custom renderer
  • pack.json, Readme_for_Users.md (Godot steps and engine notes), LICENSE.txt

Character set: 197 in each face

Printable ASCII, the full Latin-1 Supplement (French, German, Spanish, Portuguese, Italian, Dutch, the Nordic languages and Icelandic, plus symbols such as £ ¥ © ° ± × ÷ ¿ ¡ « »), and six typographic characters: ‘ ’ “ ” … —

The drips are a rule, not noise

Every Shroud letter wears the same wear. On each glyph's top row every stroke loses its left pixel (one brush angle across the face) and long bars end frayed. 34 drips hang from 32 letters, digits and marks, 2 to 4 pixels long, and only from flat strokes: a drip under a round bottom reads as an accent (an S becomes a Ş), so round letters carry none, and no drip turns a letter into another one. The drips sit inside the line height, so they never touch the next line.

Metrics

  • Sallow: line 14 px, capitals 8 px, lowercase 5 px, 31 kerning pairs. Every digit sits in one 4 px box with one 5 px advance, so counters and clocks line up; the zero is slashed.
  • Shroud: line 22 px, capitals 13 px, lowercase 9 px, 53 kerning pairs, digits in one 7 px box.
  • Use them at the native size or a whole multiple (2x, 3x...) with smoothing and hinting off; the Readme says exactly where in Godot.

The proof, measured on the files you download

  • 394 glyphs, every one inside its line box
  • 1 ink colour and alpha 0 or 255 only across 42,368 sheet pixels: no grey edge pixels, no anti-aliasing
  • 84 kerning pairs, each checked so the two letters never touch
  • 394/394 TrueType outlines draw exactly the sheet's pixels (with hinting off)
  • In a blank Godot 4.7.2 project: 15/15 test lines drawn with the .fnt match the metrics pixel for pixel, and 15/15 drawn with the .ttf match the .fnt, kerning included
