Point it at a quest your game already knows about, and it draws the finished illuminated journal page.

The errand gets its own device. The region gets its own painted roundel, and tints the whole sheet. The giver's faction is pressed into wax at the foot. The title's first letter becomes an illuminated initial on gold. The difficulty decides what the border actually is. And whether the quest is offered, in hand, discharged, lost or abandoned repaints the entire page.

Nothing in that picture is a stored image. There is no PNG, no atlas, no sprite sheet, no shader and no material anywhere in the package — 80 hand-authored forms, all drawn in C# you can read.

Getting Started

  1. Import the package. Everything lands under Assets/CSAF/Errantry/. Three assemblies, each with its own asmdef, so nothing compiles into your game unless you use it.
  2. Open the demo scene: Assets/CSAF/Errantry/Demo/ErrantryDemo.unity. Press Play. A page is drawn from the built-in twelve-quest sample journal, and the measured compose time is printed on screen. Click, or press the arrow keys, to turn to the next quest.
  3. Open the editor window: menu Window ▸ CSAF ▸ Errantry. Press Compose. The same page, plus a derivation panel naming every choice the generator made and whether it came from one of your own words or from a stable hash. Export PNG… writes the page to disk.
  4. Make your own journal: menu Assets ▸ Create ▸ CSAF ▸ Errantry ▸ Journal. Fill in some quests, drag the asset into the window's Journal slot, press Compose.
  5. From your own code, three lines: 
    var composer = new PageComposer();                 // ONE composer for the whole journal
PageCanvas page = composer.Compose(quest, PageOptions.Default(), out PageReading reading);
Texture2D texture = page.Resolve("Quest Page");

Full documentation is linked under Technical Information below. It is the same Readme that ships inside the package, readable before you buy.

It draws no text, and that is a feature

Errantry ships no font, measures no string and renders no words. It draws the page and hands you back the rectangles — in normalised UV, origin bottom-left, exactly what Unity UI takes — where your own Text, TextMeshPro or IMGUI label belongs. Your fonts, your localisation and your rich text stay entirely yours.

What your data changes

  • Kind → the errand device (14 authored).
  • Region → the painted roundel (10 authored) and the tincture of the whole page.
  • Giver → the wax seal, pressed with that faction's device (8 authored).
  • Title → the illuminated initial (26 authored letterforms).
  • Difficulty → the border's construction (5 tiers), the number of marginal drolleries, and the stroke weight of the initial.
  • ChainStep / ChainLength → the chain ornament (4 forms, summarised past nine steps).
  • State → a treatment that repaints the whole sheet (5 authored).

Kind, Region and Giver are free strings matched whole-word against your own vocabulary; an unrecognised word falls back to a stable derived mark, and the editor window tells you which fell through.

Technical Information

Features:

  • Composes an illuminated quest-journal page at runtime or in the editor, from a plain QuestRecord.
  • 80 hand-authored procedural forms: 14 errand devices, 10 region roundels, 8 giver seals, 8 marginalia, 26 illuminated initials, 5 border tiers, 5 state treatments, 4 chain ornaments.
  • Eight authored colour ramps; the region chooses the page's ramp.
  • Returns layout rectangles in normalised UV for your own text components.
  • Editor window with a derivation panel and PNG export.
  • Deterministic: the same record composes the same pixels on every machine and every run.
  • Tile cache keyed by derivation; repeated derivations rasterise nothing new.
  • 28 EditMode tests included, plus the raw commented C# for everything.

Code Modules: 3 — CSAF.Errantry.Runtime (runtime), CSAF.Errantry.Editor (Editor-only), CSAF.Errantry.Demo (runtime, demo scene only).

Number of Unity Visual Scripts: 0.

Number of .cs Scripts: 24.

Supported Development Platforms: Windows, macOS, Linux. The package is pure C# with no native plugins, no platform-specific code and no third-party dependencies.

Supported Target Build Platforms: All. Output is a Texture2D produced by a software rasteriser in managed C#; there is no shader, no compute, no native library and no platform API. Windows, macOS, Linux, iOS, Android, WebGL and console targets are all supported. Editor-only code is confined to the Editor assembly by asmdef.

Supported Unity Pipelines: Built-in Render Pipeline, URP and HDRP. The package does not touch the render pipeline at all — it hands you a Texture2D, which you can put on a RawImage, a material, a sprite, or write to disk.

Documentation: https://github.com/onefreeman1337/csaf-releases/blob/main/docs/errantry/README.md — a full written manual covering the data model, the integration surface, every field's effect on the drawing, measured performance figures and the product's stated limits. The same file also ships inside the package as the user Readme.

Example Project: Included. Assets/CSAF/Errantry/Demo/ErrantryDemo.unity is a scene you press Play on; it composes a page from a built-in twelve-quest sample journal that deliberately exercises all five states, all five difficulty tiers, a three-step chain, a twelve-step chain, a quest with no Kind, a title starting with a digit and a region no corpus word matches.

Versioning: 1.0.0. Built and gated against Unity 6000.5.7f1 with warnings as errors; minimum supported Editor version 2022.3 LTS.

Support: Questions, bug reports and feature requests through the Fab seller contact form, or through the CSAF storefront reachable from our publisher profile. The full source ships readable and uncompressed, and every mark in the corpus is a plain C# method you can edit.

Limits, stated plainly

  • It does not lay out text, and will not. You place the words.
  • The corpus is fantasy-medieval. The mechanism is general; the 80 forms are a manuscript vocabulary.
  • It is a software rasteriser: a 720x1000 page takes about 4.5 s cold and 2.7 s with a warm composer, measured by the included test suite on the machine that built it. Compose when a quest changes, keep the texture, never call it in Update. A 259x360 index thumbnail takes about 161 ms.
  • The page is portrait by default. Landscape works; the layout was authored for a leaf.
