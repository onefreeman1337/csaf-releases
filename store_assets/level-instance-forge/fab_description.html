First-time test (2 minutes)

This plugin has no editor panel. It is a headless commandlet: you run one command, and it writes a self-contained HTML page you open in a browser. The interface shown in the screenshots is that written page — the proof sheet the tool produces — not a window inside the editor. There is nothing to dock and no menu item to find.

Copy the plugin folder into YourProject/Plugins/, restart the editor once so it builds, then run:

UnrealEditor-Cmd.exe "C:\path\to\YourProject.uproject" -run=LevelInstanceForge -Scan -Paths=/Game/Maps

That is a report. It opens every map under the paths you name, decides every cluster, and writes nothing. It leaves one file in YourProject/Saved/LevelInstanceForge/:

LevelInstanceForge_<timestamp>.html — open it in any browser. Every repeated arrangement, ranked by how many actors converting it would remove, each member's offset, rotation and scale, and every cluster the tool declined to touch with the reason written out in a sentence.

When you agree with the sheet, add two switches to write it:

UnrealEditor-Cmd.exe "C:\path\to\YourProject.uproject" -run=LevelInstanceForge -Forge -Apply

-Apply is a separate switch deliberately, so no single mistyped flag can change your project: -Forge on its own still previews. An applied run writes a JSON journal before the first package is saved, and that journal is what undoes it:

UnrealEditor-Cmd.exe "C:\path\to\YourProject.uproject" -run=LevelInstanceForge -Revert=Saved/LevelInstanceForge/LevelInstanceForge_<timestamp>.json

The same three operations are available from the editor console as LevelInstanceForge.Run -Scan if you prefer. Run with no mode for the full switch list.

Renderer and materials: the commandlet does not need a renderer and runs headless on a build agent. It does not modify materials, shaders or any rendering setting; it moves existing actors into a Level Instance asset and leaves every material assignment exactly as it found it.

What it is for

Your levels repeat the same arrangement of actors dozens of times, and Unreal cannot convert them in bulk.

The same lamp post, base and two bollards, hand-placed forty-seven times across six maps. The Level Instance is the engine's own answer to this: one source map holding the arrangement once, referenced by cheap actors wherever it appears. Converting to it is the right fix.

Converting in bulk is not currently possible. Epic's ULevelInstanceSubsystem::CreateLevelInstanceFrom sets bUseSaveAs unconditionally, which routes it through SaveLevelAs rather than the silent save that accepts a filename — and that ends in a modal Save-As dialog, inside a retry loop, once per cluster. The package name the caller supplies is ignored. Epic filed this as UE-309562 and it remains open in 5.8.

Level Instance Forge does the part the engine leaves to you, and then performs the conversion itself, headlessly.

Getting Started

Features:

It finds the repeats. Not repeated meshes — repeated arrangements. The same objects, in the same relative positions, at the same relative angles, wherever they appear across every map you name.

It proves two arrangements are the same one. Each cluster is expressed relative to an anchor chosen by an ordering that is invariant under any rigid transform, so a cluster rotated ninety degrees and placed in a different map produces a byte-identical signature to the original. That invariant is the product, and an automation test in the shipped source asserts it directly.

It does not trust its own hash. A matching signature is a candidate, never a verdict. Candidates are confirmed against real position, rotation and scale tolerances, and a bucket whose members merely quantise alike is split rather than merged. Rotations are compared as the angle between quaternions rather than component-wise, because two identical rotations can differ in every Euler value.

Then it converts. It creates the source map, replaces every occurrence with a single Level Instance, and saves — with no dialogs.

It refuses when it cannot be certain. A wrong conversion deletes hand-placed art with the originals already gone, so anything it cannot prove identical is reported and left exactly as it was: actors attached to something outside their cluster, clusters whose anchor is non-uniformly scaled, symmetric rings where too many members tie for the anchor, and clusters over the size cap. Two arrangements that differ only by a material override are different arrangements and never merge; the report shows the material each member carries, so the distinction is visible rather than implied.

Nothing is written without -Apply, and the undo journal is on disk before the first package is saved, so -Revert restores every actor with its mesh, materials and transform.

Stable exit codes, for CI. 0 ok, 1 bad arguments, 2 the scan could not read the project, 3 forge incomplete, 4 revert incomplete. Exit 2 is never "your project is clean" — a clean project exits 0 with an empty sheet.

Technical Information

Code Modules:

LevelInstanceForge (Editor)

Number of Blueprints: 0

Number of C++ Classes: 1 UCLASS commandlet plus 8 plain C++ headers (arguments, scanning, clustering, forging, journal, report, run, types)

Network Replicated: No

Supported Development Platforms: Windows

Supported Target Build Platforms: Win64

Engine Version: Built and verified against Unreal Engine 5.8 on Windows. That is the only engine it was gated on and the only version claimed.

Editor only: Yes. The module is Type Editor and ships nothing into a packaged game.

Third party software: Does not include third party software. Every dependency is an Epic engine module.

World Partition: Ordinary levels and World Partition maps are both handled; partitioned maps store each actor in its own package and those are gathered through the asset registry's external-actor folders, so there is no separate mode to select.

Documentation: Full documentation, including the argument reference, the exit-code table and a worked three-step example: https://github.com/onefreeman1337/csaf-releases/blob/main/docs/level-instance-forge/README.md
