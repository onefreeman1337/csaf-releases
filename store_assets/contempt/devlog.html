CONTEMPT is a courtroom game where the trial is the fight. This post is about the number that made it one, because the first version of the design did not work and the reason was measurable.

The problem: a perfect reader could not lose

The game is built on a model that runs headless, so it can be played by machine thousands of times before a person ever sees it. The first sweep was 40 seeded trials per case against a model that reads every telegraph correctly and objects on the right frame. It won 100% on all five opponents — a flat line where the design says there is a curve.

The obvious fix is to make the model human. It was given a reaction time of 12 to 18 frames, drawn once per bout, which is the ordinary range for a trained visual choice. It still won 100% of all five.

The cause was an income stream nothing touched

Counting what the model actually did in a bout of the hardest case was what settled it. It was taking five unanswered arguments and five overrulings — about eighty points of verdict damage — and still finishing eighty points ahead, because it also landed 21 presses in the gaps between arguments.

Pressing was free money. So every difficulty dial the design owned — the width of the objection window, the feints, the compound arguments — was competing against an income stream that none of them touched. No amount of tightening the windows could have fixed it.

The fix is the burden of proof

The jury now drifts toward the prosecution on its own. Standing still loses. A player has to generate a positive rate, not a positive total, which is the one quantity a long safe bout was exploiting.

That produced a second failure immediately, and it is the more interesting one. With a flat drift the hard cases all ended on the clock: case five read a healthy-looking 65.8% win rate with a median bout of 150.0 seconds — the jury clock exactly. That is what a tug of war looks like at equilibrium, and raising the drift only moves which side the stalemate settles on.

So the drift scales with the jury's own lean. A lead compounds and a deficit bites, which means trials end. Case five's median fell from 150 seconds to 78 in one change.

Where it landed

Judged at 120 seeds per arm, 2,400 trials, against bands written down before the run:

  • a skilled player wins 100 / 100 / 82.5 / 52.5 / 47.5 percent across the five cases
  • a first-timer wins 37.5 / 29.2 / 0 / 0 / 0
  • spamming the illegal button — hitting opposing counsel on cooldown — wins 0% on every case
  • doing nothing at all wins 0% and always loses on the verdict, never by timing out

Every band has a ceiling as well as a floor. A one-sided threshold cannot detect drift in its permissive direction, and the permissive direction is the one things rot in.

One more thing, and it is the one that would have shipped

The on-screen objection buttons passed a class name where the keyboard passed an index. Tapping one threw inside the animation frame and killed the render loop — the game froze on its last drawn frame while its own state reported that a trial was still running. The automated playthrough passed 32 checks out of 32 straight through it, because it objected with the keyboard and only tapped menu buttons. Two input paths, one tested.

It is fixed, the harness now taps a real objection button and proves the model saw it, and the screen-capture tool listens for page errors — because a capture tool that does not check the page is alive is photographing a freeze.

The game is free and plays in the browser. Five cases, eight permanent precedents, and a mistrial that keeps everything you have won.
