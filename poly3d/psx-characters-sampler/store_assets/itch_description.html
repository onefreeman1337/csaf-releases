PSX Characters Sampler is a free pack of 5 low poly PS1-style 3D characters for Godot 4, Unity and Unreal: a mechanic, a knight, a high priest, a rifleman and an innkeeper. Each is rigged to one humanoid skeleton with 45 animation clips, has 1495-1499 triangles and one 256 px texture per skin (16 skins in total), in GLB, FBX, OBJ and Blender formats, with a PSX shader for Godot 4. Free to use in any number of commercial games, no attribution required. Each character comes from one of our five paid PSX character packs (69 characters in all).

One character from each pack, with every file the full pack ships for that character, so you can drop them into your project and see the look in your own engine first.

In your project

Godot 4: copy models/ and shaders/ into the project, instance a _skin0.glb, put the PSX shader on the mesh. Tested here in a blank Godot 4.7.2 project: every GLB imports, the shader compiles on every character, the clips play (Godot names Walk_Loop as Walk and loops it). The in-engine images on this page are that test.

Unity 6 / Unreal 5: import the FBX (skeleton and clips included) and set the textures to point / nearest filtering. The skeleton is a standard humanoid, built to retarget (Unity Humanoid, Unreal IK Rig). These two engines were not run here; the FBX files were re-imported in Blender to check that mesh, 53 bones and every clip arrive.
