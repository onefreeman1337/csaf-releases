Colophon - Save Slots That Draw Themselves, for GameMaker is a GameMaker asset for GameMaker, paid.

Colophon is a save system whose save screen is drawn from the saves. It writes versioned save slots - with an autosave, migrations for when your save format changes, and loads that refuse a damaged file by name - and it draws every slot as a printed leaf composed from the run that slot holds.

So a save list stops being rows of text and becomes a shelf of different objects: the save from the harbour on a deckle-edged sheet, the late-game save in a beaded binding with a dog-eared corner, the fighter's run sealed with crossed swords and the hoarder's with a stack of coins. Six readings of one save Device - what the run has been: fighting, walking, hoarding, levelling or reading.

15 devices, five families of three marks that mature as the run goes on Paper - where it was saved: a village prints on laid paper, a crypt on vellum, a harbour on deckle. 8 papers Binding - how far into the game: 6 tiers, from a hairline rule to a beaded, cornered border Wear - how long it has been played: toning, foxing, a fold, a dog-ear.

5 states House - every leaf of one game shares an ink scheme chosen from its title.
