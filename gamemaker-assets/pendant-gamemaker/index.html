Pendant - Spot the Difference From Any Picture, for GameMaker is a GameMaker asset for GameMaker, paid.

Any picture in your game becomes a spot-the-difference puzzle, hung as a pair of paintings in a gallery. Pendant hangs the picture twice and changes the second copy in as many places as you ask: an object added that belongs where it lands, a detail mirrored, something painted out, or an object recoloured.

Every change is generated and measured to be visible before it is kept, so you never paint a second picture by hand. Use it for a museum heist, a detective's photo board, a festival minigame in an RPG, or a whole spot-the-difference game.
