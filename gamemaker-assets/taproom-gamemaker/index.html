Taproom: 4 Tavern Board Games with AI for GameMaker is a GameMaker asset for GameMaker, paid.

Taproom puts 4 old board games into GameMaker 2024: Nine Men's Morris, Fox and Geese, Oware and Fanorona, played at a drawn tavern table against an opponent at five strengths, royalty free in commercial games. What is inside 4 games · 8 board materials · 6 sets of men · 5 opponent strengths · 192 table combinations · a demo tavern with six regulars.

Every board is drawn in GML: slate, marble, a knifed tabletop, black lacquer, a linen mat, tooled leather, walnut and brass, carved soapstone. The opponent searches a slice of each frame, so the game never stalls, and the same position with the same seed gets the same move. The opponent's name picks their board and men, so the old man in the corner always sets out the same scratched slate.

Three calls run a game: tpm_table_open, tpm_table_step and tpm_table_draw. The result comes back as won, lost or drawn with a margin. Records against each opponent save to a JSON string for your own save file. The eight boards, each with its own line work, border and wear. Nine Men's Morris in play, with the moves the player may make ringed.

Works with GameMaker 2024, tested on runtime 2024.14.4.268 (the stable runtime, Windows VM).
