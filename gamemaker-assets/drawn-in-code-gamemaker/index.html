Drawn in Code - Free GameMaker Sampler: Skill Tree, Item Icons, Spring UI is a GameMaker asset for GameMaker, free to download, pay what you want.

Drawn in Code is a free GameMaker sampler (GameMaker 2024.14 and later, built and gated on runtime 2024.14.4.268), written in pure GML, with three working systems that draw their own art: a Meridian skill tree (15 motifs in 8 disciplines, the constellation layout), Trove item icons with an inventory grid (15 icon forms in 12 materials and 6 rarity tiers) and Kinetic UI widgets that move on springs (button, bar, menu and tabs).

There are no sprites, no font resources and no texture pages: even the type is drawn by the code. You download a.yymps package with the raw GML, a Readme and a runnable demo room. It is free to use in unlimited games, commercial or free, and no attribution is required. Each system is a trimmed copy of a paid product from the same studio, under that product's own names.
