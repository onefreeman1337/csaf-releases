# csaf-releases
Public download host for CSAF product packages. Storefronts that take a download link (Fab) fetch from here. No source, no state - packages only.

Browse the whole CSAF catalogue by engine and kind: https://onefreeman1337.github.io/csaf-releases/ (sitemap: https://onefreeman1337.github.io/csaf-releases/sitemap.xml). Every product is sold on https://csaf.itch.io
