Its title or description names Unity 6.

Unity bakes lighting per scene. A room you build as a prefab and spawn at runtime arrives with no baked lighting at all: a looping hallway, a procedural dungeon or a pooled level chunk is lit only by its lights in real time. Flat, no bounce light, no soft baked shadows, and a pixel light budget that runs out after a few rooms.

Roomlight bakes each room prefab once, on its own, and every spawned copy carries that bake. What it does Bakes each room prefab alone with Unity's own lightmapper, at the texel density, page size and padding you set per room. Your open scenes are put back afterwards and your prefab's static flags are never changed. Writes the bake into the prefab.

The lightmap pages go beside the prefab, and a Roomlight Room component records which page each renderer reads and where. Baked lights carry their baking output too, so a spawned copy never lights itself twice. No code at runtime. A copy binds when it is enabled and lets go when it is disabled or destroyed. Copies of one room share one set of pages.

Your scene's own lightmaps are never touched, freed slots are reused, and after a scene load Roomlight puts its pages back if Unity rebuilt the list.
