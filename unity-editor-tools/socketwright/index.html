Socketwright - Modular Kit Sockets and Snap Placement for Unity

Socketwright - Modular Kit Sockets and Snap Placement for Unity is a Unity editor tool for Unity, paid.

Its title or description names Unity 6.

Point it at a folder of modular kit prefabs. It reads the meshes and writes the connection sockets for you. Then drop a piece near another one and it snaps, rotation resolved. Other modular snapping tools make you place every socket by hand, piece by piece, in a custom editor.

Socketwright derives them from the geometry, for the whole kit, in one pass: an opening socket in every hole of a piece's boundary faces (corridor ends, doorways cut into a room) and an edge socket on every thin, full boundary face (wall ends, floor edges, wall tops for stacking). The size of the hole or edge becomes the mating type, so a 3.5 x 3 corridor end only mates with another 3.5 x 3 opening.

Measured on Unity 6000.5.7f1 The 11-piece demo kit ships with NO hand-placed sockets. Socketwright derived 33 sockets from the meshes and detected the 4 m module by itself. The demo level was then assembled through those sockets, every joint mated. A 200-prefab kit derives and writes in one pass: 602 sockets, every prefab saved.
