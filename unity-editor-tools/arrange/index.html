Arrange - Animator Auto Layout for Unity is a Unity editor tool for Unity, paid.

Its title or description names Unity 6.

Unity's Animator window cannot lay out a state machine. Arrange does: pick a controller, see the new layout next to the old one with the crossings counted, and write it in one Undo step. States land where you drop them, and after a few months a character controller is a pile of overlapping nodes and crossing transition arrows.

Arrange reads every state, sub-state machine and transition in a view (Entry, Any State, Exit and the Up node included), puts the states in columns flowing out from Entry, orders each column to cut crossings, and straightens long transitions so they run between states instead of through them. It moves nodes and nothing else.

Measured on Unity 6000.5.7f1 Knight sample (locomotion, a Combat sub-state machine with a nested Finisher, Reactions, Any State hits), all four views: crossings 52 to 6, lines through states 64 to 19, overlaps 12 to 0. Drone sample, an 18-state enemy AI loop: crossings 110 to 13, lines through states 50 to 5, overlaps 3 to 0.

Shopkeeper sample, two layers: crossings 9 to 1, lines through states 14 to 3, overlaps 4 to 0. The Knight.controller file before and after, line by line: 2,651 lines, 49 changed, every one of them a position line.
