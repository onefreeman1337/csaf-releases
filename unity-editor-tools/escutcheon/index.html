A Unity editor tool from Core Systems Asset Factory. Made with Unity. Paid.

Escutcheon is a Unity editor tool for Unity, paid.

Escutcheon Illustrated character sheets, generated from the stat block you already have. Point it at a character and it composes a finished sheet: a heraldic crest built from their class and house, an emblem for every attribute chosen from your own attribute names, a border that grows more ornate as they advance, merit roundels for their titles, and rank pips for their level. Your players see it. That is the point.

Nothing in this package is an imported image Every mark is drawn in C# by a software rasteriser that ships with the tool as readable source. There is no sprite atlas, no texture, no shader, no material and no network call anywhere in the art path. That is not a technical boast, it buys you four things: It works on Built-in, URP and HDRP with no variants and nothing to configure, because there is no shader to break.

It is deterministic. The same character produces byte-identical artwork on every machine and in every session. The test suite asserts this. It runs headlessly. No graphics device. It works in batch mode, on a build agent, and in an EditMode test. It scales. The same emblem is drawn at 44 pixels in the attribute grid and at 300 on the crest, from one code path.
