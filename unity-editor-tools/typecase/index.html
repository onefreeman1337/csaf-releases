Typecase - Pixel Font PNG Sheet to TextMesh Pro Font Asset for Unity 6 is a Unity editor tool for Unity, paid.

Its title or description names Unity 6.

TextMesh Pro only builds a font asset from a TTF or OTF file, so a pixel font that exists as a PNG sheet cannot be typed in TMP at all. Typecase reads the sheet and writes a real TextMesh Pro font asset, with the colours, outlines and shadows you drew kept exactly.

Not a sprite asset: a font asset, so it works in every TMP text, input field and dropdown, with kerning, word wrap, rich text and fallbacks, in UI and in world space. What it does Three ways to read a sheet: a grid of equal cells, automatic detection by the blank space around each glyph (on transparency or a solid background colour), or an AngelCode BMFont.fnt file in text format. Keeps your colours.

Two-tone fills, outlines and drop shadows drawn into the sheet render as drawn. Or switch the font to Tint From Text and colour a one-colour font with TMP's colour field and <color> tags. Measures the font from your letters: baseline, ascent, descent, cap height, x-height and the space, all in whole pixels, plus kerning pairs and per-glyph adjustments. Rebuilds in place.

Save the PNG from your art program and the font asset updates itself; every text using it keeps its reference.
