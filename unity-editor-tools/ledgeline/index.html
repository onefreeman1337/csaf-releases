Ledgeline - Jump-Up, Drop and Gap NavMesh Links for Unity 6 is a Unity editor tool for Unity, paid.

Its title or description names Unity 6.

Unity's NavMesh bake makes links for dropping DOWN off a ledge and for jumping ACROSS a level gap. It has no setting for jumping UP. So an agent drops off a crate and can never climb back on, and every upward route is a NavMesh Link you place by hand, then place again whenever the level changes. Ledgeline reads your baked NavMesh and places them for you. Give it your agent's jump height, drop height and gap length.

It places real NavMeshLink components on every ledge your agents can climb, drop or leap, both ways where both ways work, and tests every jump arc against your level so no link goes through a wall or under a beam. What it does Four kinds of link, from one profile: two-way Ledge links where the agent can climb and drop, one-way Jump Up and Drop links where it can only do one, and two-way Gap links.

Neighbouring points along a ledge merge into one wide link. Reads your agent. Radius, height and step height come from the NavMesh agent type, so the profile can never drift from the bake. Rises the agent can simply walk up get no link. Tests the arc, not just the ends. Each candidate's jump arc is checked against your colliders.
