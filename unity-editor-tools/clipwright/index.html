Clipwright — Animation Clip Workbench for Unity is a Unity editor tool for Unity, paid.

Derive the clips you need from the clips you have. Trim, retime, mirror, loop and clean AnimationClip assets, a whole folder at a time, with exact curves and real.anim files beside the source. Every animation library arrives slightly wrong for the project it lands in.

The walk is 4 frames too long, the idle pops when it loops, the attack is right-handed and you need a left-handed one, the run is 20% too slow, and every clip carries dozens of curves that never move. Unity's importer can fix some of that for clips inside an FBX. It does nothing for a standalone.anim, and its mirror is humanoid-only. Clipwright is the bench for everything after import.

The five steps Tick the ones you want. They run in this order and each one writes counts to a report you can read. Trim to a frame range. Keys are cut on the curve with its own value and exact slope, so the kept range plays identically to the source (measured: 16 curves, 300 samples each, worst difference 0.0000001). Retime faster or slower.

Key times and tangents are scaled together, never resampled: 2.4 s becomes 1.6 s with the same 73 keys. Mirror left and right, including generic rigs (see below).
