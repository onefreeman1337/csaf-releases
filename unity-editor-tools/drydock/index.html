Drydock: The Loadout Schematic Sheet is a Unity editor tool for Unity, paid.

Its title or description names Unity 6.

Your refit screen already knows what the player is flying. Drydock draws it. Hand it your parts list and it composes a technical drawing: a blueprint ground with a ruled frame and zone marks, the hull in silhouette, one drawn fitting per hardpoint with a leader line that lands on the drawing, a callout carrying the station and the spec, and a filled title block with a struck approval stamp.

You write no drawing rules. You hand it a list of parts.

Loadout l = Loadout.Empty("KESTREL III", "Interceptor", Stock.Cyanotype); l.Fittings.Add(new PartFitting { Name = "Ion Thruster", Station = "AFT 1", Spec = "2.4 GW", Grade = 4 }); l.Fittings.Add(new PartFitting { Name = "Railgun", Station = "SPINE", Spec = "88 MJ", Grade = 5, Revised = true }); Texture2D sheet = DrydockSheet.Compose(l, 1024, 720); That is the whole API surface you need.

47 part silhouettes, and not one of them is an image file Hulls, propulsion, power, weapons, protection, sensors, utility and structure — every one drawn in code as a signed-distance field, at whatever size you ask for. There is no atlas, no sprite sheet and no resolution to outgrow. The package ships zero image files.
