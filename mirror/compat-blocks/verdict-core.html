⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. VerdictCore.js — Investigation & deduction engine — exhibits establish facts, testimony carries claims, and presenting the wrong one costs you.
  2. VerdictCaseFile.js — Verdict Core's look — the Case File, the Cross-Examination and the corkboard Case Board. Nothing here uses a windowskin.

VerdictCore must come before VerdictCaseFile.

Core methods extended — all 2 by saved-original prototype extension, none replaced: Scene_Boot.prototype.start, Game_System.prototype.initialize.

Because nothing is clobbered, Verdict Core co-exists with other plugins that patch the same seams, including large suites.
