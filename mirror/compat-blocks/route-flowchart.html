⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. ThreadsMotifs.js — Threads — the ending-emblem motif corpus. 48 hand-authored marks in six families. Load BEFORE Threads.js.
  2. Threads.js — Threads — a player-facing story flowchart, ending gallery and branch jump. Requires ThreadsMotifs.js above it.
  3. ThreadsUI.js — Threads — the chart scene, the ending gallery and the emblem renderer. Load BELOW Threads.js.

Threads resolves its dependencies lazily, so a wrong order will not silently break it — but this is the order to use.

It extends exactly one core method, by saved-original prototype extension, not replaced: Scene_Boot.prototype.start.

Because nothing is clobbered, Threads (player-facing story flowchart & branch jump) co-exists with other plugins that patch the same seams, including large suites.
