⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. BazaarCore.js — The economy under the shop: stock that actually runs out,
  2. BazaarMarketUI.js — The market screen for Bazaar Core: live prices, remaining
  3. CSAF_Theme.js — CSAF visual layer — procedural window frames, type scale, easing and a bloom filter. Makes a plugin stop looking like RPG Maker.

BazaarCore must come before BazaarMarketUI. CSAF_Theme is adopted at boot, so its position does not matter.

Core methods extended — all 14 by saved-original prototype extension, none replaced: Window_ShopBuy.prototype.price, Window_ShopBuy.prototype.isEnabled, Window_ShopBuy.prototype.drawItem, Window_ShopBuy.prototype.priceWidth, Scene_Shop.prototype.maxBuy, Scene_Shop.prototype.doBuy, Scene_Shop.prototype.sellingPrice, Scene_Shop.prototype.doSell, Window_ShopSell.prototype.isEnabled, Window_MenuCommand.prototype.addOriginalCommands, Scene_Menu.prototype.createCommandWindow, Scene_Boot.prototype.start, Scene_Shop.prototype.create, Scene_Base.prototype.update.

Because nothing is clobbered, Bazaar Core co-exists with other plugins that patch the same seams, including large suites.
