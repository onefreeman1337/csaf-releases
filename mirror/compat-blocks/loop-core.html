⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. LoopCore.js — The time-loop engine. The world resets, the player does not. Anchors, rewinds, carried knowledge and loop-gated events.
  2. LoopLedger.js — The Loop Ledger scene. Every loop a ring, every divergence a pin, everything known a constellation.
  3. LoopRewind.js — The rewind. A full-screen time-collapse shader that plays while the world snaps back to the anchor.

LoopCore is required; LoopLedger and LoopRewind are optional and can be switched off without breaking the loop.

Core methods extended — all 2 by saved-original prototype extension, none replaced: Game_System.prototype.initialize, Game_System.prototype.onAfterLoad.

Because nothing is clobbered, Loop Core co-exists with other plugins that patch the same seams, including large suites.
