⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. VoyageCore.js — Sea travel as gameplay. Wind, points of sail, cargo weight, spoilage, storms and ports whose prices move because you sailed there.
  2. VoyageChart.js — The sea chart. Hand-drawn parchment, live wind, a course you ink in as you sail it. Requires VoyageCore.
  3. VoyageManifest.js — The cargo manifest: a ruled ship's ledger with wax seals, keeping-time bars and a weight beam. Requires VoyageCore.

VoyageCore is required; VoyageChart and VoyageManifest are optional scenes.

Core methods extended — all 2 by saved-original prototype extension, none replaced: Game_System.prototype.initialize, Game_System.prototype.onAfterLoad.

Because nothing is clobbered, Voyage Core co-exists with other plugins that patch the same seams, including large suites.
