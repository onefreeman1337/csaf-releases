⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. ChimeraField.js — Biome spawn tables with rarity tiers, level bands, time and
  2. ChimeraDexUI.js — Field Guide scene for Chimera Field. Species log driven by
  3. CSAF_Theme.js — CSAF visual layer — procedural window frames, type scale, easing and a bloom filter. Makes a plugin stop looking like RPG Maker.

Order matters only in that ChimeraDexUI must come after ChimeraField. CSAF_Theme is adopted at boot rather than at load, so it can go anywhere in your list.

Core methods extended — all 7 by saved-original prototype extension, none replaced: Window_MenuCommand.prototype.addOriginalCommands, Scene_Menu.prototype.createCommandWindow, Scene_Boot.prototype.start, Game_Map.prototype.setup, Game_System.prototype.initialize, Game_Player.prototype.makeEncounterTroopId, Scene_Base.prototype.update.

Because nothing is clobbered, Chimera Field co-exists with other plugins that patch the same seams, including large suites.
