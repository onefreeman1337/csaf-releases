⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. ChronicleCore.js — A quest ENGINE, not a journal: branching outcomes that
  2. ChronicleJournalUI.js — The scene for ChronicleCore: open quests, finished ones,
  3. CSAF_Theme.js — CSAF visual layer — procedural window frames, type scale, easing and a bloom filter. Makes a plugin stop looking like RPG Maker.

ChronicleCore must come before ChronicleJournalUI. CSAF_Theme is adopted at boot, so its position does not matter.

Core methods extended — all 4 by saved-original prototype extension, none replaced: Scene_Boot.prototype.start, Window_MenuCommand.prototype.addOriginalCommands, Scene_Menu.prototype.createCommandWindow, Scene_Base.prototype.update.

Because nothing is clobbered, Chronicle Core co-exists with other plugins that patch the same seams, including large suites.
