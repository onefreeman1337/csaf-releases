⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. ApertureCore.js — The camera your player actually aims. Viewfinder, focus, framing score, and an album of developed prints.
  2. ApertureLens.js — The look of Aperture Core: viewfinder chrome, real depth-of-field blur, focus peaking, the shutter, and developed prints.
  3. ApertureAlbum.js — The camera and the album, as playable scenes. Binds Aperture Core to RPG Maker.

ApertureLens and ApertureAlbum both declare ApertureCore as their base, so the editor itself warns you if the order is wrong.

It extends exactly one core method, by saved-original prototype extension, not replaced: Game_System.prototype.initialize.

Because nothing is clobbered, Aperture Core co-exists with other plugins that patch the same seams, including large suites.
