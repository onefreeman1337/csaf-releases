Godot 4 Shader and VFX Sampler: 132 free presets from 11 addons

A free download for Godot 4.7: 11 2D addons with 132 ready presets between them, MIT licensed. Every preset is a shader, particle system or drawing script computed while the game runs, with its colours, sizes and speeds exposed in the inspector. Each folder holds twelve real presets of one paid pack, the same nodes and its own demo.

How to use it

  1. Unzip. Each of the 11 folders holds a godot/ folder that is a complete Godot 4.7 project.
  2. In the Godot Project Manager press Import, pick that project.godot, press Play: the demo shows every free preset of that pack.
  3. To use one in your own game, copy that folder's godot/addons/<name>/ into your project. All 11 install side by side in one project.

Plain GDScript and .gdshader files, readable and editable. Tested on Godot 4.7.2 under Forward+ and Compatibility; older versions were not run.
