Three free RPG Maker MZ minigames made from any picture in your project.

Any Picture Minigames Sampler is three free plugins for RPG Maker MZ (1.x core scripts). Jigsaw Lite cuts any picture from your img/pictures folder into a 9 piece jigsaw the player assembles on a drawn felt table. Pendant Lite hangs the picture twice in a gilt gallery with 3 generated differences to find. Unveil Lite hides it under a silk veil the player cuts away, Qix style. One plugin command each, one result switch each, a demo picture included. Free to use in commercial and non commercial games.

Each is a small fixed cut of a paid plugin from the same studio, cut from its code: one size of Jigsaw's 4 to 256 pieces, one 3 difference round of Pendant's 1 to 12 of four kinds, one board of Unveil's three veils. Upgrade and the Lite's command hands the game to the full plugin, so no event has to change.

⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. CSAF_JigsawLite.js — Jigsaw Lite (free): cuts any picture in your project into a 9-piece jigsaw the player assembles on a drawn table.
  2. CSAF_PendantLite.js — Pendant Lite (free): any picture in your project, hung twice in a gallery, with 3 generated differences to find.
  3. CSAF_UnveilLite.js — Unveil Lite (free): a Qix-style minigame, claim the silk veil to reveal any picture in your project.

It patches no core RPG Maker method at all, so there is nothing of anyone else's for it to collide with.

What is in the zip

  • CSAF_JigsawLite.js: plugin command Start a jigsaw. A new 3 x 3 cut every time; drag pieces with mouse or finger, or carry them with the keyboard hand; a piece near its home snaps in. Parameter: Solved -> switch.
  • CSAF_PendantLite.js: plugin command Start a spot-the-difference. The second copy changed in 3 places (a detail mirrored, a patch painted out), each measured to be visible before it is kept; finds ringed in ink, misses marked. Parameter: All found -> switch.
  • CSAF_UnveilLite.js: plugin command Start Unveil. Reveal 75% of the picture with 3 lives, one creature in the veil and two sparks on the edge. Parameter: Won -> switch.
  • img/pictures/CSAF_Harbour.png: a demo picture to try them with. Readme_for_Users.md and LICENSE.txt.

The three files do not depend on each other: take one, two or all three. Each event waits while its minigame is open and carries on when the player leaves, so a Conditional Branch on the switch can follow directly. MZ only (not MV).

Tested before release

Every Lite is checked against the paid plugin's own code (the same cut, the same differences, the same game rules frame for frame), played to a win and a loss in the real MZ engine through an event, installed fresh from this zip into a blank project and saved and loaded, and run above and below its full version in the Plugin Manager.
