Also inside the MZ Plugin Library: every CSAF MZ plugin in one download, and every new one joins it.

Stride gives every walking sprite in RPG Maker MZ 29 new drawings: 3 plugins add a real run cycle, idles and gaits, made from each character's own walking sheet.

Three parts, 8 raw JavaScript plugin files, no image files. Nothing to draw: the hero, the followers and every event get their drawings when they first need them. Use one part, any two, or all three: each works alone, and all three were tested together in the engine. Licence: any commercial or free RPG Maker project, no royalty; the source may not be redistributed as a plugin pack.

⚠️ Compatibility: the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. PostureCore.js: Posture core - derives sitting, kneeling, lying, sleeping, collapsed, waving and cheering frames from a walking sheet. Place ABOVE Posture.
  2. KnackCore.js: Knack core - derives 12 looping work animations (with a drawn tool) from a walking sheet. Any order works; PostureCore, KnackCore, Knack reads best.
  3. StrideCore.js: Stride core - derives a six-frame run cycle in four facings from a walking sheet.
  4. StrideRun.js: Stride Run - a real run cycle when characters dash, drawn from their own walking sprites.
  5. StrideIdleCore.js: Stride Idle core - derives nine idle drawings in four facings from a walking sheet.
  6. StrideIdle.js: Stride Idle - characters that stand still breathe, blink, shift their weight, glance around, set their hands on their hips and doze, drawn from their...
  7. StrideGaitsCore.js: Stride Gaits core - derives a limp, a tired trudge, a sneak, a wade, a jump tuck and a landing in four facings from a walking sheet.
  8. StrideGaits.js: Stride Gaits - characters limp at low HP, trudge when tired, sneak, wade through water and tuck their knees in a jump, drawn from their own walking...

Core methods extended: 12 by saved-original prototype extension, none replaced: Game_BattlerBase.prototype.refresh, Game_BattlerBase.prototype.recoverAll, Game_CharacterBase.prototype.update, Game_CharacterBase.prototype.realMoveSpeed, Game_Player.prototype.isDashing, Sprite_Character.prototype.updateBitmap, Sprite_Character.prototype.characterBlockX, Sprite_Character.prototype.characterBlockY, Sprite_Character.prototype.characterPatternX, Sprite_Character.prototype.patternWidth, Sprite_Character.prototype.patternHeight, Sprite_Balloon.prototype.updatePosition.

Nothing is clobbered: every file saves the original method and calls it, so other plugins that patch the same seams keep running. Tested with only these plugins loaded; not tested with VisuStella Events and Movement Core or other plugins that swap walking sheets.

Stride Run: a real run

  • When the player dashes, the party runs instead of walking faster: 6 drawings in each of the 4 facings.
  • A long stride, a lean into the run, arms bent and pumping, in the sheet's own colours.
  • Tag an event to make it run too.

Stride Idle: standing still

  • A character that stands still breathes, blinks, shifts its weight, glances around, sets its hands on its hips and dozes: 9 drawings in each facing.
  • Each character keeps its own rhythm, so a crowd never breathes in step.

Stride Gaits: the game decides

  • A limp below 25% HP, a tired trudge when poisoned, a crouched sneak on the Hide state, wading on the water tiles you mark, a tucked jump and a landing: 14 drawings in each facing.
  • Switched on by HP, states, switches, regions and jumps. No event commands needed.

Tested together

  • One hero, three parts: he idles standing, runs on the dash key, and at low HP limps even with the dash key held.
  • A limper standing still idles; a poisoned follower keeps its tired drawing while it stands.
  • One save carries all three parts and still loads with any one turned off. The same checks pass in three plugin orders.
