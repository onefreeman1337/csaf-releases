Every icon in your menus moves by what it is. Blades glint, gems twinkle, potions bubble, fire flickers with embers, key items pulse. Living Icons reads your database to decide which effect each icon gets and reads the icon's own pixels to decide where the light goes, so there are no frames to draw and nothing to tag.

Restrained on purpose. Each icon plays briefly and then rests, and identical icons in one list move out of step, so a full inventory shimmers instead of strobing. Greyed entries stay greyed. It works in every window that draws icons: items, skills, equipment, shops, status.

⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. LivingIconsCore.js — [Living Icons 1.0 core] Reads each icon and bakes its animation. Install DIRECTLY ABOVE LivingIcons.js.
  2. LivingIcons.js — [Living Icons 1.0] Every icon in your menus moves by what it is: blades glint, gems twinkle, potions bubble, fire flickers.

Core methods extended — 3 by saved-original prototype extension, none replaced: Window_Base.prototype.drawIcon, Window_Base.prototype.createContents, Window_Base.prototype.update.

Because nothing is clobbered, Living Icons co-exists with other plugins that patch the same seams, including large suites.

Chosen by what the entry is

  • Weapons glint: a streak of light with a white core crosses the blade. A weapon with the Fire attack element flickers instead.
  • Metal armour glints; accessories twinkle on their own brightest points.
  • Recovery items bubble; key items pulse with a gold halo.
  • Skills by element: fire flickers with embers, thunder sparks, ice glints, water bubbles, light and dark pulse. Element names are matched by meaning, so renamed elements still work.
  • <Living Icon: glint> forces any effect; <Living Icon: none> keeps an icon still.

Works with your icons, whatever style

RPG Maker's stock icons are white glyphs on coloured tiles; Living Icons reads them as a glyph on a tile, so sparkles and bubbles land on the glyph, never on the tile's border. Free-standing pixel-art icons are read by their own silhouette. If another plugin draws its own picture where an icon would go, Living Icons checks the pixels it expects and leaves that picture alone.

What is in the box

  • Two plain, readable JavaScript files: LivingIconsCore.js (reads each icon and bakes its animation) and LivingIcons.js (plays them in every window), plus a user guide.
  • Three parameters (speed, intensity, effects to leave out), two notetags, and script calls, all in the guide.
  • The store images use our own icons: the gems are drawn by Facet and the vessels by Glaze, baked into an IconSet. No icon art is included in this download; it animates yours.

How it was tested

Run in the real RPG Maker MZ runtime from the exact zip you download, installed into a blank project with RPG Maker's stock database: the stock sword glints in the stock item menu. Every row of the effect table, both notetags, every parameter and script call in the guide were exercised, and an adversarial pass threw bad icon indices, fifty refreshes in a row, recreated window contents and unknown notetags at it. Each icon's frames are made once and played from one shared texture: on the item menu with every entry animated, a frame shows no texture uploads and no growth in display objects.
