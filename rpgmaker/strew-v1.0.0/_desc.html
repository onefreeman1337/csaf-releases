Strew dresses the maps you made by hand, from your own tileset, in one keypress. Walk onto a map in playtest and press F7: flowers gather in drifts, one kind of flower to a drift; bushes, rocks and stumps settle against trees, walls and water; a field of one repeated grass tile is broken up by its own variants. Press F7 again for a different arrangement, Shift+F7 to take it back.

It knows where things must not go. Nothing lands on a road, on or beside an event, on a region you keep clear, or on a square that already has an upper tile. Before it places anything that blocks, it proves the squares around it stay connected, so it never cuts a route. Undo removes exactly what Strew placed and keeps anything you painted since.

⚠️ Compatibility — the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order:

  1. StrewCore.js — [Strew 1.0 core] The map-dressing engine Strew.js drives. Install DIRECTLY ABOVE Strew.js.
  2. Strew.js — [Strew 1.0] Dresses your own maps from your own tileset in one keypress: flower drifts, tufts at the walls, floor variants.

Core methods extended — 2 by saved-original prototype extension, none replaced: Scene_Map.prototype.isReady, Scene_Map.prototype.start.

Because nothing is clobbered, Strew co-exists with other plugins that patch the same seams, including large suites.

Drifts, not sprinkles

Random scatter reads as noise, which is worse than a bare map. Strew places by rules a mapper would use: a slow field decides where flowers gather and which flower each drift is; flowered grass fills appear only around the drifts; tufts and pebbles thicken where ground meets something solid; rocks sit in corners; stumps and logs stay rare and near trees. The second image compares it with the same tiles dropped at random on the same map.

From your tileset, not ours

  • Stock RPG Maker MZ sheets: on the stock Outside sheet Strew uses a palette picked by hand (bushes, a rock pile, stumps, logs, dead branches, cracks, stones, tufts and six kinds of flower), so it never scatters barrels, signposts or snowmen. Inside, Dungeon, SF and World sheets get floor variants only.
  • Any other tileset: Strew reads the art. Small objects that sit inside their square are sorted by colour into flowers, tufts, bushes, rocks, pebbles and wood; floor tiles that match each other in every quadrant, edge and corner become interchangeable variants.
  • See the reading: F6 opens the plan view, which shows every tile Strew will place with its tile ID, the roads, the squares kept clear for events, the drift field and each placement. Correct anything with a tileset note such as <Strew Exclude: 140>.

Bake or Live

  • Bake (playtest): F7 writes the dressed map to data/MapXXX.json and keeps the file it replaced in data/Strew/ (the newest five per map). Rerolls never stack.
  • Live: put <Strew Live> in a map's note and the map is dressed in memory each time it loads, the same way every time, with no file written. Works in deployed desktop and web games.
  • Save files are never touched in either mode.

What is in the box

  • Two plain, readable JavaScript files: StrewCore.js (the dressing engine) and Strew.js (bake, reroll, undo, Live mode, the result card and the plan view), plus a user guide.
  • Six parameters (density, keep-clear regions, kinds to leave out, Live on every map, hotkeys, the result card), four plugin commands, six map notes and three tileset notes, all in the guide.
  • No tileset images are included. The store images use Verdant 01 Overworld, our own tileset, sold separately.

How it was tested

Run in the real RPG Maker MZ runtime from the exact zip you download, installed into a blank project on the stock Outside tileset: a real F7 and Shift+F7, a Live map, and a stock Inside map that must scatter no furniture. Every parameter, command and note in the guide was exercised, and an adversarial pass threw broken notes, corrupted files, missing files and a 300 by 300 map at it. On the busiest scenario (a Live-dressed map with the party walking, the result card up and the plan view showing) a frame costs 11 draw calls, with no texture uploads and no growth in display objects.
