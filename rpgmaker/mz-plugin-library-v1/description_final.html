Works with

RPG Maker MZ. Install a plugin by copying its folder's js/plugins files into your project and turning them on in the Plugin Manager in the order its Readme gives. Each plugin's own page and Readme carry its compatibility block: what it extends, the Plugin Manager order and notes for VisuStella MZ Core Engine. Some also run in RPG Maker MV through CSAF_MVBridge.js; their Readme says so.
