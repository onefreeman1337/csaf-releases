Stride Run is in. When the player dashes, MZ plays the walk faster; Stride Run gives every character a real run instead: six drawings in each of the four facings, made from the character's own walking sheet when it is first needed. The hero, the followers, and any event you tag. No run art to draw. Four plugin files, and this page is where it ships first.

The GIF is engine frames, side by side: on the left the same character dashing the way MZ draws it (the walk, faster), on the right with Stride Run. Each panel follows its runner across a courtyard painted for the capture; in your game it is your own map.

  • Six drawings a cycle: contact, pass and flight, then the same with the other leg leading. From the side the stride is long, the heel kicks up behind, both feet leave the ground and the body leans into the run.
  • The arms are redrawn bent at the elbow and pump opposite to the legs, in the sheet's own sleeve, skin and outline colours. The far arm and leg are a shade darker.
  • The player and followers run while the player dashes. An event runs when it is tagged <stride: run>, or you set a speed. <stride: walk> keeps a slime or a cart on its own sheet.
  • The pace follows the move speed: 7 frames a drawing at dash speed, and a Cadence parameter.
  • Tested on MZ 1.10.0: the run of all 116 test characters with nothing drawn outside its cell and every contact and pass drawing standing on the floor, the stock hero running from the shipped zip in a blank project, and a frame gate at 9 draw calls and 0 texture uploads with four characters running laps.

New in the download: the folder 01-your-own-sprites-and-icons/stride-run (four plugin files, the Readme and the licence). PostureCore and KnackCore are the same files Posture, Knack and Rally ship, byte for byte.
