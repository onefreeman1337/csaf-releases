Fetch is an RPG Maker MZ plugin that copies your party into real enemies for a mirror-match boss, drawn from each hero's own battler sheet in 10 looks. Two plugin files, no art to draw, commercial use with no royalty. Read the documentation before you buy.

These pictures use our own HD battlers and backdrops; neither ships. Your twins come from your art, and one plate shows stock-size sheets on a bright field.

A fetch is a folklore double, and this one is read from the live hero when the fight starts: level, stats, equipment, traits and learned skills. A database enemy freezes the day you type it.

What you get

  • Ten looks: Shadow, Void, Mirror, Ink, Ember, Frost, Phantom, Gilded, Glitch and Crimson, on every frame of the sheet.
  • All 18 side-view motions, and front-view battles drawn from the hero's map sprite, which walks on the spot.
  • A brain that chooses as it moves: it heals an ally under half HP, takes a kill, and hits the hero its skills hurt most, taking the best choice about 7 times in 10 by default.
  • Habits: each twin leans toward what its hero has really been used for.
  • An entrance: each hero's floor shadow crosses the field and the twin rises from it.

Three ways to use it

  • The Mirror Match command starts the fight.
  • Arm the Next Battle, then Battle Processing, keeps your If Win branch.
  • Note an enemy <fetch: party> or <fetch: member 2> and place it in any troop. Each twin earns its rewards.

Max HP defaults to 60% because full-HP fights run long; 100% is an exact copy.

Compatibility: the question you actually have

Tested against RPG Maker MZ with the stock scripts unmodified, verified by running the plugin in the real engine rather than only in tests.

Plugin Manager order: FetchCore.js, Fetch.js. Any order works.

Core methods extended: 21 by saved-original prototype extension, none replaced. The full list is in the guide.

Because nothing is clobbered, Fetch co-exists with other plugins that patch the same seams. It is tested with the stock scripts only.

It defines 5 methods its classes only inherited: if another plugin redefines one of those, load Fetch after it.

Not tested with VisuStella Battle Core: it is a paid plugin that has not been run against Fetch here, and it adds its own side-view enemy path, so try one fight before relying on the two together.
