Footfall: Footstep Matrix, 12 Surfaces x 4 Gaits x 3 Weights is a sound effect pack, paid.

One foot, 12 grounds 576 footsteps indexed the way a footstep system asks for them: surface x gait x weight, with 4 takes in every cell, plus 12 seamless walking loops. 588 files in total. Every step in this pack is made by the same foot: one heel, roll and toe for each gait, one sole, one body mass. Only the ground changes.

So a character walking from grass onto stone sounds like one character changing ground, not like the game switching sound libraries mid stride.
