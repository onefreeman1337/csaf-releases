Blip — Dialogue Voices for Text-Advance is a sound effect pack, paid.

104 dialogue sounds. 13 speakers, not one blip pitched 13 ways. New: Blip 02, a second cast. Thirteen more speakers with the same eight cues and the same file names, measured against these thirteen so that none of the 26 collide.

And Blip 03, a third cast: thirteen speakers for school, modern and cozy games (a teacher, a principal, a toddler, a cat), the same eight cues and file names, measured against all 26 earlier voices so that none of the 39 collide. Also new: Babble 01, syllabic dialogue voices.

The other text advance style: ten speakers who talk in made up syllables instead of beeps, in five moods, with a letter map so a word always sounds the same. Text advance blips are the sound almost every RPG and visual novel needs, and almost nobody sells properly. The usual pack gives you one blip, and a cast made by pitching that one blip up and down, so a party of six reads as one instrument playing a scale.

This pack is 13 genuinely different voices. Each one is a different synthesis method, not a different frequency: a ringing two pole resonator, a formant pair excited by noise, a bit crusher, a narrow pulse behind a low filter, a wide detune with a long tail.
