119 sound effects for the part of a roguelike no dungeon pack covers: the run itself. A generic dungeon pack sells the door and the chest. Descent sells the loop a player repeats forty times: starting a run, going down a floor, meeting a threat, finding something rare, running low on HP, dying, and spending what they carried home. It is built so the sound tells the player which run this is before they read a number.

8 ladders: wire a number to a rung floor descent (6 rungs, wired to floor depth), threat tier (5 rungs, wired to threat tier), low hp heartbeat (5 rungs, wired to HP), item rarity (5 rungs, wired to item rarity), gold amount (4 rungs, wired to gold amount), meta unlock tier (5 rungs, wired to meta unlock tier), run summary tally (5 rungs, wired to run score), floor ambience by depth (4 rungs, wired to depth band).

Two run downward on purpose. Every floor you descend is darker than the one above, and the low HP heartbeat is a set of seamless loops whose period falls rung by rung, so swapping loops as HP drops makes the heart race.
