# Pocketful: 432 modern-day item icons

432 pixel-art icons of everyday modern objects at **32 x 32 px**, 378 of them also at **16 x 16 px**, in 8 categories: phones, laptops and consoles, school and office supplies, money, cards, keys and tickets, food, drinks and kitchenware, clothing and accessories, sports, hobbies and toys, medicine and personal care, and tools and home items. Hard pixels on a transparent background, one 55-colour palette across the whole pack, an RPG Maker MZ IconSet.png sheet, and files for Godot 4, Unity, Unreal, GameMaker and Ren'Py.

Made by Core Systems Asset Factory. The art is AI-generated (see LICENSE.txt).

## Two sizes, honestly

Every icon is drawn at 32 x 32. Its 16 x 16 version was reduced from that drawing by our own code (each 2 x 2 block takes its most common colour, the outline is re-drawn at 16 px, and no colour is added), then looked at beside its 32 px original. 54 small versions did not read at 16 px (thin wires, rings of keys, a deck of cards, clocks whose hands vanish) and were left out, so 378 of the 432 icons come in both sizes and the other 54 at 32 px only. `atlas/atlas.json` gives `png16` and `rect16` as null for those. Icon *i* sits at the same column and row in `atlas_32.png` and `atlas_16.png`, so one index serves both sheets.

## Every icon is a different item

All 432 icons were looked at one by one. Frames with defects were removed before packing: garbled lettering on packaging, objects that read as one named brand, and featureless frames. Some different items share an outline: pens, keys and screwdrivers all lie on the same diagonal, and many bottles share one shape. Our near-duplicate check (a 9 x 8 greyscale outline hash, the strictest one we run) finds 335 of the 432 icons with no outline twin anywhere in the pack; `atlas/atlas.json` marks those `"pairFree": true`. The other 97 are different items that share an outline with at least one sibling (a ballpoint pen and a screwdriver, a credit card and a train ticket).

No icon carries a brand name, a logo or written words; the only marks are a clock face, keypad dots and small symbols.

## What is inside

| Folder | What |
| --- | --- |
| `png/32/<category>/<id>.png` | 432 icons at 32 x 32, one PNG each |
| `png/16/<category>/<id>.png` | 378 icons at 16 x 16, one PNG each |
| `atlas/atlas_32.png`, `atlas/atlas_16.png` | every icon on one sheet per size, 16 columns: 512 x 864 and 256 x 432 |
| `atlas/atlas.json` | the index: id, name, category, PNG paths, both atlas rectangles, MZ icon index and `pairFree` of every icon |
| `palette.json` | the 55 colours every opaque pixel uses, as 13 ramps |
| `godot/` | a Godot 4 project: both atlases, one AtlasTexture `.tres` per icon per size, and a demo scene that shows all 432 and the 378 small ones |
| `unity/` | both atlases with their `.meta`: Sprite (Multiple), one named sprite per icon, Point filter, 32 or 16 pixels per unit |
| `unreal/icon_rects.csv` | name, category, size, pixel rectangle and 0..1 UVs of every icon on its atlas |
| `gamemaker/icons.json` | every icon's PNG paths and atlas positions, with a suggested sprite name |
| `rpgmaker_mz/img/system/IconSet.png` | an RPG Maker MZ IconSet (32 px cells, 16 columns): icon index 1 to 432; index 0 is left empty as MZ expects |
| `rpgmaker_mz/iconset_index.csv` | which icon index is which item |
| `renpy/game/` | both atlases and `pocketful_icons.rpy`: `image item_<id>` (32 px) and `image item16_<id>` (16 px) |

## Engines

- **Godot 4** (tested in a blank Godot 4.7.2 project (freshinstall_godot.js 20/20, both sizes, 2026-11-27)): copy `godot/pocketful/` into your project. Each icon is `res://pocketful/icons/<id>.tres` (32 px) or `res://pocketful/icons16/<id>.tres` (16 px), an AtlasTexture you can put on a Button, TextureRect, Sprite2D or ItemList. Keep the texture filter on Nearest (Project Settings > Rendering > Textures > Default Texture Filter) so the pixels stay hard. Open `godot/project.godot` to see the demo.
- **RPG Maker MZ** (tested in the RPG Maker MZ runtime, blank project (freshinstall_mz.js 5/5 + negative control red, 2026-11-27)): back up your project's `img/system/IconSet.png`, then copy ours over it. Item, weapon, armour and skill icons are then picked by index in the database; `iconset_index.csv` says which index is which item. This replaces MZ's stock icons; to keep yours, paste our rows under them in an image editor and add your row count x 16 to each index.
- **Unity** (files for this engine; not yet run in it): drop `unity/atlas_32.png` (and/or `atlas_16.png`) with its `.meta` into `Assets/` together. Unity reads each as one Sprite (Multiple) texture with one named sprite per icon, Point filter.
- **Unreal Engine** (files for this engine; not yet run in it): import `atlas/atlas_32.png` or `atlas_16.png` with Filter = Nearest and Compression = UserInterface2D; `unreal/icon_rects.csv` gives each icon's rectangle and UVs per size (for a Paper2D sprite per row, or UV offsets in a material).
- **GameMaker** (files for this engine; not yet run in it): import any `png/32/...` or `png/16/...` file as a sprite, or load an atlas at run time and draw parts of it with the positions in `gamemaker/icons.json`. Turn off texture interpolation for crisp pixels.
- **Ren'Py** (files for this engine; not yet run in it): copy `renpy/game/` into your game folder; `pocketful_icons.rpy` defines `image item_<id>` and `image item16_<id>` (for example `add "item_red_apple"`).
