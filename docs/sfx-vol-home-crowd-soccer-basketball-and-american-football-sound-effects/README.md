# Home Crowd: Soccer, Basketball and American Football Sound Effects in Three Packs

**344 sound effects in 3 kits, WAV and OGG, for any game engine: Soccer (121 sounds, the pitch, the goal frame and the stands), Basketball (113 sounds, the court, the rim and the shot clock) and Football (110 sounds, American football, the snap, the pads and the stadium).**

Three sports, each as the plays a game scores: soccer on an open stadium pitch, basketball in an indoor arena and on an outdoor court, American football in a floodlit stadium, each with its own acoustic language and its own ladders a game can map to a power value. Each pack is complete in its own folder, with its own Readme, licence, naming manifest and proof, so you can copy one folder into a project and leave the others.

Made by Core Systems Asset Factory. Every sound is synthesised from code: no samples, no recordings, no third party audio, no generative audio model. Nothing here is musical.

## The kits

| Folder | Kit | Sounds | Loops |
|---|---|---|---|
| `Soccer/` | Home Crowd Soccer: Pitch, Goal Frame and Stands Sound Effects | 121 | 6 |
| `Basketball/` | Home Crowd Basketball: Court, Rim and Shot Clock Sound Effects | 113 | 10 |
| `Football/` | Home Crowd Football: Snap, Pads and Stadium Sound Effects | 110 | 7 |
| | **Total** | **344** | **23** |

**Soccer**: Soccer is an open stadium pitch at night. One ball body is struck on every touch, by a boot that makes it brighter as it strikes harder. The kick, the header and the stands are ladders a game can map to a power or excitement value; the goal frame is a grid (target by power), so a game changes one word in a file name when a shot rattles the post instead of the net; the sprinklers start, run as a seamless loop and stop.

**Basketball**: Basketball is an indoor arena over a sprung maple floor, with an outdoor asphalt court for the second dribble ladder. One ball body is rung by the floor, the hands and the rim. The dribbles and the arena are ladders a game can map to a force or excitement value; the basket is a grid (result by shot), so a game picks the file from its own shot result and distance; the shot clock, the backboard and the ball rack start, run as seamless loops and stop.

**Football**: Football is a floodlit concrete stadium with a long slapback off the stands. One oblong ball body is rung by hands, boots and the turf; pads and helmets are hard shells over foam. The kick, the throw and the stadium are ladders a game can map to a power or excitement value; contact is a grid (surface by force), so a game picks the file from what was hit and how hard; the sled, the tarp and the launcher start, run as seamless loops and stop.
