Derive the clips you need from the clips you have.

Clipwright is an editor window for AnimationClip assets. Select clips or a folder, tick the steps you want, watch the source curve and the result drawn over each other, and press Write. Every result is a normal .anim file beside its source, with no runtime component and no dependency on the tool. Open it from Window ▸ CSAF ▸ Clipwright.

Every animation library arrives slightly wrong for the project it lands in: a walk four frames too long, an idle that pops when it loops, a right-handed attack when you need a left-handed one, a run 20% too slow, dozens of curves that never move. Unity's importer fixes some of that for clips inside an FBX. It does nothing for a standalone .anim, and its mirror is humanoid-only. Clipwright is the bench for everything after import.

Five steps, each exact

Trim to a frame range: keys are cut on the curve with its own value and exact analytic slope, so the kept range plays identically to the source (measured: 16 curves, 300 samples each, worst difference 0.0000001). Retime faster or slower: key times and tangents scale together and nothing is resampled, so 2.4 s becomes 1.6 s with the same 73 keys. Mirror left and right, including generic rigs. Close a loop seam: the gap between the last pose and the first is blended in over the last N seconds, everything before that window is untouched, and quaternions are matched to the nearest sign so a q and -q pair is never fixed with a full turn. Clean constants: curves that never change drop to two keys with evaluation unchanged, and no curve is ever deleted.

Mirroring generic rigs, and when it refuses

Generic rigs rarely share an axis convention between their left and right bones, so a mirror written as negate-these-two-components is only right for the rig it was written for. Clipwright reads your rig's rest pose instead and re-expresses every rotation and position curve on the partner bone, so the result is the true reflection whatever each bone's axes are. The demo rig proves it: its right bones point Z down the bone and its left bones point X with a 37 degree twist, and across 1,911 transform positions the mirrored pose sits at the reflection of the source to within 0.0000005 m. Partners are found by whole-token names (LeftArm, Arm_L, arm.l, L_Arm, Arm_L_01). It refuses a rig with the reason when there are no pairs, when the rest pose is more than 1% asymmetric, when a bone and its partner hang from parents that are not mirrors, or when two transforms share one path. Humanoid clips are mirrored with Unity's own Mirror flag. Euler rotation curves are moved to the partner bone but not reflected, and the report counts them.

Safe to run again

It never writes to a source clip, and a naming pattern that would resolve to the source is refused. Output is named {name}_{steps} by default (Wave_R_Mirror, Stride_x1p5). Run it again and an existing derived clip is updated in place, so its GUID and every Animator state or Timeline clip pointing at it keep working, and that update is one Undo step. Batch writes run inside AssetDatabase.StartAssetEditing and StopAssetEditing. Everything the window does is public API in CSAF.Clipwright.EditorTools for build scripts.

What ships

Two assembly definitions (Editor, Demo), the Editor one platform-constrained so none of it reaches your player build. No Resources folder, no package dependencies, no render pipeline dependency, no network calls. A demo scene you press Play on: seven figures, three authored clips and the four clips the tool derived from them (Wave_R_Mirror, Stride_Loop, Stride_x1p5, Reach_R_Trim). Full readable source with XML documentation on public API.

Getting Started

1. Import the package. Everything lands under Assets/CSAF/Clipwright/.
2. Open Assets/CSAF/Clipwright/Demo/Scenes/ClipwrightDemo.unity and press Play: seven figures, three authored clips and the four clips Clipwright derived from them.
3. Open the bench from Window ▸ CSAF ▸ Clipwright.
4. In the Project window select Demo/Clips/Wave_R (or the whole Clips folder) and press Use Project selection.
5. Tick Mirror and drag Demo/Rig/Mannequin into the Rig field. The preview draws the source curve in grey and the result in teal.
6. Press Write. Wave_R_Mirror.anim appears beside the source; change a setting and press Write again to update the same asset in place.
