# Satchel: 794 fantasy RPG item icons

794 pixel-art item icons at **32 x 32 px** in 13 categories: weapons, armour, shields, jewellery, potions, food, ores and gems, crafting materials, magic items, tools, treasure and furniture. Hard pixels on a transparent background, one 56-colour palette across the whole pack, and every icon ready for Godot 4, Unity, Unreal, GameMaker, RPG Maker MZ and Ren'Py.

Made by Core Systems Asset Factory. The art is AI-generated (see LICENSE.txt).

## Every icon is a different item

All 794 icons were looked at one by one; frames with defects (garbled lettering, empty or featureless frames) and any item drawn twice were removed before packing. Some different items share an outline: sixty swords all lie on the same diagonal, and six potions share one bottle in six colours. Our near-duplicate check (a 9 x 8 greyscale outline hash, the strictest one we run) finds 449 of the 794 icons with no outline twin anywhere in the pack; `atlas/atlas.json` marks those `"pairFree": true`. The other 345 are different items that share an outline with at least one sibling (a frost sword and a flame sword, a red and a blue mana vial).

## What is inside

| Folder | What |
| --- | --- |
| `png/32/<category>/<id>.png` | 794 icons at 32 x 32, one PNG each |
| `atlas/atlas_32.png` | every icon on one sheet, 16 columns, 512 x 1600 |
| `atlas/atlas.json` | the index: id, name, category, PNG path, atlas rectangle, MZ icon index and `pairFree` of every icon |
| `palette.json` | the 56 colours every opaque pixel uses, as 13 ramps |
| `godot/` | a Godot 4 project: the atlas, one AtlasTexture `.tres` per icon, and a demo scene that shows all 794 |
| `unity/` | the atlas with its `.meta`: Sprite (Multiple), one named sprite per icon, Point filter, 32 pixels per unit |
| `unreal/icon_rects.csv` | name, category, pixel rectangle and 0..1 UVs of every icon on the atlas |
| `gamemaker/icons.json` | every icon's PNG path and atlas position, with a suggested sprite name |
| `rpgmaker_mz/img/system/IconSet.png` | an RPG Maker MZ IconSet (32 px cells, 16 columns): icon index 1 to 794; index 0 is left empty as MZ expects |
| `rpgmaker_mz/iconset_index.csv` | which icon index is which item |
| `renpy/game/` | the atlas and `satchel_icons.rpy`: one `image item_<id>` per icon |

## Engines

- **Godot 4** (tested in a blank Godot 4.7.2 project (freshinstall_godot.js 17/17, 2026-11-23)): copy `godot/satchel/` into your project. Each icon is `res://satchel/icons/<id>.tres`, an AtlasTexture you can put on a Button, TextureRect, Sprite2D or ItemList. Keep the texture filter on Nearest (Project Settings > Rendering > Textures > Default Texture Filter) so the pixels stay hard. Open `godot/project.godot` to see the demo.
- **RPG Maker MZ** (tested in the RPG Maker MZ runtime, blank project (freshinstall_mz.js 5/5 + negative control red, 2026-11-23)): back up your project's `img/system/IconSet.png`, then copy ours over it. Item, weapon, armour and skill icons are then picked by index in the database; `iconset_index.csv` says which index is which item. This replaces MZ's stock icons; to keep yours, paste our rows under them in an image editor and add your row count x 16 to each index.
- **Unity** (files for this engine; not yet run in it): drop `unity/atlas_32.png` and its `.meta` into `Assets/` together. Unity reads it as one Sprite (Multiple) texture with 794 named sprites, Point filter, 32 pixels per unit.
- **Unreal Engine** (files for this engine; not yet run in it): import `atlas/atlas_32.png` with Filter = Nearest and Compression = UserInterface2D; `unreal/icon_rects.csv` gives each icon's rectangle and UVs (for a Paper2D sprite per row, or UV offsets in a material).
- **GameMaker** (files for this engine; not yet run in it): import any `png/32/...` file as a sprite, or load the atlas at run time and draw parts of it with the positions in `gamemaker/icons.json`. Turn off texture interpolation for crisp pixels.
- **Ren'Py** (files for this engine; not yet run in it): copy `renpy/game/` into your game folder; `satchel_icons.rpy` defines `image item_<id>` for every icon (for example `add "item_red_apple"`).
