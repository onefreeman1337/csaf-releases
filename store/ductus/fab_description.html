Ductus generates letter tracing lessons from your own font, in Latin, Cyrillic and Greek.

Every other tracing asset ships hand drawn paths for one alphabet. Ductus carries the one thing a font cannot tell you, the order and direction a letter is written in, and takes the letterform from whatever font your project already uses. Pick a font, pick a script, and you have 177 tracing plates that match your game.

What you get

  • 177 glyph lessons: Latin A to Z, a to z and the figures (62), the full Russian alphabet including the two Io letters (66), and alpha to omega including the final sigma (49).
  • 341 authored strokes, each in the order and direction a child is taught to write it. No font file records that, so it cannot be read off an outline. It is written out, once, per glyph.
  • Font fitting: the strokes are warped onto your font’s own letterforms, and every glyph is graded fitted, approximate, or fell back. You see the survey before you export anything.
  • Designed plates: ruled paper, a letter shaped track to keep the crayon inside, a dashed centre guide, numbered start dots and a direction arrow at every turn. Six colourways, any plate size to 2048.
  • A stroke demonstration that writes the letter at constant pen speed, with a pen nib, at any moment you ask for.
  • A runtime tracing board for mouse and touch that raises events when a stroke lands, when the glyph is finished, and when the child goes the wrong way.
  • An editor window at Window ▸ CSAF ▸ Ductus, a playable demo scene, and full readable source.

Why the grades are in front of you

Fitting a stroke skeleton to a real letterform is not always possible, and a generator that pretends otherwise hands you a confident wrong path. A single storey a is not the double storey a a child is taught, and a heavy display face is not a handwriting model. Ductus says so, per glyph, and falls back to its own canonical form so the lesson is still correct even when it no longer matches the face. On a plain text face, 164 of the 177 lessons grade fitted. That number was measured in an empty project against Unity’s own built in font, not estimated.

Notes

  • Unity 2022.3 or newer. No package dependencies, no Resources folder, every script in a named, platform constrained assembly definition.
  • Ductus ships no fonts. It reads yours at edit time and draws pictures of letters, so your font’s own licence governs the sheets you export. A font under the SIL Open Font License is safe for this. Ductus never copies, embeds, subsets or redistributes any part of a font file.
  • Plates are drawn in software, with no shaders and no render textures, so they are identical on every platform and in batch mode.
  • Full readable source. Nothing is obfuscated, minified or compiled away.

Getting Started

  1. Import the package. Everything lands under Assets/CSAF/Ductus.
  2. Open Assets ▸ CSAF ▸ Ductus ▸ Demo ▸ DuctusDemo.unity and press Play. Trace the letter with the mouse, starting on the dot marked 1 and following the arrows. The strip along the top changes script, letter and colourway.
  3. To make your own sheets, open the editor window at Window ▸ CSAF ▸ Ductus.
  4. Drop a dynamic font into the Font field and choose a Script (Latin, Cyrillic or Greek).
  5. Press Survey this font. Every letter is fitted and graded, and the grid colours each one. Click any letter to see its plate and the numbers behind its grade.
  6. Set an export Folder inside Assets, tick which grades to include, and press Export. You get one PNG per letter.
  7. To put a lesson in your own scene, add a SpriteRenderer and a CSAF ▸ Ductus Tracing Board component to any GameObject, set Character, and press Play.

Technical Information

Features: 177 glyph lessons across Latin, Cyrillic and Greek, each with its strokes in the taught order and direction; font fitting that warps those strokes onto the buyer’s own font with a per glyph quality grade; designed tracing plates with ruled paper, a letter shaped track, a dashed centre guide, numbered start dots and direction arrows; six colourways; a stroke by stroke demonstration; a runtime tracing board for mouse and touch with stroke, completion and mistake events; an editor window with a fit survey and PNG export; a playable demo scene.

Code Modules: CSAF.Ductus.Runtime (Runtime, all platforms), CSAF.Ductus.Editor (Editor only), CSAF.Ductus.Demo (Runtime, all platforms).

Number of Unity Visual Scripts: 0

Number of .cs Scripts: 14

Supported Development Platforms: Windows, macOS

Supported Target Build Platforms: Windows, macOS, Linux, iOS, Android, WebGL. The runtime draws in software with no shaders and no render textures, so it has no platform specific code path.

Supported Unity Pipelines: Built-in, URP and HDRP. The package renders into a Texture2D and does not touch the render pipeline.

Example Project: A demo scene ships in the package at Assets/CSAF/Ductus/Demo/DuctusDemo.unity. Open it and press Play.

Versioning: 1.0.0

Support: csassetfactory@gmail.com

Documentation Link: https://github.com/onefreeman1337/csaf-releases/blob/main/docs/ductus-letter-tracing-generator/README.md

Important/Additional Notes: The package ships no fonts and no third party content of any kind. It reads a font already present in the buyer’s project at edit time and draws its own plates; your font’s licence governs the artwork you export. Minimum Unity version 2022.3.

Made with AI

Code: yes. Graphics: yes. Sounds: no, this package ships no audio. Text and dialog: no. The plates are not produced by an image model. They are drawn in code by a software rasteriser included in the package, from a hand authored stroke corpus you can read and edit, warped onto outlines read from your own font by a fitter also included in the package. There is no diffusion model and no network call anywhere in the art path.
