RPG mouse cursors with their hotspots, animated menu fingers and a selection frame that fits any slot Fingerpost is an RPG cursor and selection kit: 17 mouse cursors (plated gauntlets in point, grab and open, a steel arrow, inspect, talk, attack, cast, use, loot, unlock, enter, forbidden, target, move, text and an 8 frame busy hourglass), each with its hot pixel shipped as data and inside 60 Windows.cur files, plus animated menu fingers and chevrons, battle target arrows and rings, an animated 9 slice selection frame, a menu row highlight, tile, name entry and caret cursors, and a full game UI in one armoured steel and gilt theme.

86 widgets in 191 widget states, pixel mode and HD mode, with files for Godot 4 (4.7 tested), Unity 6 (tested), RPG Maker MZ (tested), Unreal Engine, GameMaker and Ren'Py.
