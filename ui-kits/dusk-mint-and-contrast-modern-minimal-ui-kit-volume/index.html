Three modern minimal UI themes in one kit: a dark mode, a soft pastel and a high contrast theme, switchable at runtime Dusk, Mint and Contrast is a UI kit volume for casual, puzzle, cozy and any modern looking game: three complete themes with 58 widgets in 145 widget states each, in pixel mode and HD mode, with files for Godot 4 (4.7 tested), Unity 6 (tested), RPG Maker MZ (tested), Unreal Engine, GameMaker and Ren'Py.

Every theme shares the same widget names, state names and Godot theme types, so a game can offer a dark mode or a high contrast option with one line of code. 20 interactive widgets per theme also ship a focused state for keyboard and gamepad navigation. Royalty free licence for commercial games. A free sampler of all three themes is on this page. Dusk: dark mode.

Charcoal panels with light hairline edges, rounded corners, a cyan accent, an amber focus ring. Same frame geometry and 9 slice margins as our light kit Clean Slate, so the two work as a light and dark pair. Mint: soft pastel. Soft mint outlines, pill shaped buttons, cream panels lying flat, a rose danger colour, a violet focus ring. Contrast: high contrast.
