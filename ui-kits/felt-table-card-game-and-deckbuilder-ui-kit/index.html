Felt Table: Card Game and Deckbuilder UI Kit (Pixel + HD) is a game UI kit for Ren'Py, Unity, Unreal Engine, GameMaker, RPG Maker and Godot, paid; its description points to a free sampler.

A card table UI kit for deckbuilders and card games, ready for six engines 88 widgets in 173 widget states, in pixel mode and HD mode, generated from one theme and wired for Godot 4, Unity, Unreal Engine, GameMaker, RPG Maker MZ and Ren'Py.

Lacquered mahogany rails around green baize, a brass line inlaid in every heavy rail and a brass playing card suit in each of its corners (spade, heart, club, diamond), brass buttons with dark ink, crimson lacquer for the card back and for danger.

Every element in the gallery is a file in the pack: the battle screen and the shop screen at the top of the gallery are built only from the kit's own sprites, 9 sliced to size. The card table 4 card frames, one per card type (attack, skill, power, curse), each in normal, hover, selected and disabled. Base size 52x74 in pixel mode, 3x in HD. Every card frame is a 9 slice that stretches like a card.

The cost gem and the name plate sit in the top margin and the rules box in the bottom margin, so a card can be drawn at any size (hand, zoomed, inspect) and only the art window grows; the gem, the name plate and the rules box keep their size. The gallery shows one frame sliced to four sizes.
