A strict four-colour UI kit for handheld style games, ready for six engines and GB Studio 59 widgets in 126 widget states, in pixel mode and HD mode, generated from one theme in exactly four colours and wired for Godot 4, Unity, Unreal Engine, GameMaker, RPG Maker MZ and Ren'Py, with GB Studio frame and cursor files. Four colours, and it is checked Every pixel of the pixel art is one of four colours at full opacity (or fully transparent): no blends, no translucent overlay, no fifth shade.
