A phone and chat UI kit for visual novels: a handset, chat bubbles, conversation rows and a lock screen, ready for six engines Phone Line is a pixel art phone and chat UI kit for visual novels and story games, with 102 widgets in 186 widget states, in pixel mode and HD mode, with files for Ren'Py, Godot 4 (4.7 tested), Unity 6, Unreal Engine, GameMaker and RPG Maker MZ.

It includes 44 phone and chat pieces (a stretchable handset, chat bubbles with tails, typing dots, read ticks, conversation rows, a lock screen banner, call keys, status bar glyphs and home screen tiles), 47 stretchable 9 slice widgets in all, a Godot theme and a working chat demo, and a royalty free licence for commercial games. A free sampler is on this page, and a free sampler of all our UI kits is linked below.

Dark mode: night blue panels with a soft rim one step lighter than each fill, violet for the player's messages, slate for everyone else's, rose for danger and for declining a call, a graphite handset. Every element in the gallery is a file in the pack: the three phone screens at the top of the gallery are built only from the kit's own sprites, 9 sliced to size.
