Verdant Forge is a tileset generator you run yourself. Open one HTML file in a browser — no install, no account, no internet, no Node, no Python, no build step — pick a palette, and export a complete, ready-to-import pack. Not a pack you get once. A pack you get whenever you need one, in whatever palette your game actually uses.

New in 1.1 — it builds interiors too Set Scene to Interior and the same engine lays out rooms. Set it to Both and you get an overworld and the insides of its buildings in one pack, one palette, one grid — so the buildings match the world they stand in.

The wall uses the identical 47-mask enumeration the terrain uses, so your autotiler needs no second code path, and the furniture is lit from the upper left like every other object in the set. Existing owners: this is a free update, and the 228 outdoor tiles are byte-identical to the ones you already have. What comes out, every time 428 tiles — Outdoors: 23 ground fills, 188 autotile transitions and 17 props.
