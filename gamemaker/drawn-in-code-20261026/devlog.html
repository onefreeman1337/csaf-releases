Drawn in Code is out, and it is free: a GameMaker project with three working systems that draw their own art, so you can try the look in your own game before buying anything.

Inside is a trimmed copy of three of our paid GameMaker systems, each under its own names. Meridian builds a skill tree from what each node needs, places every node from that graph and draws every node's mark from its motif; the sampler carries 15 of its 60 motifs and the constellation layout. Trove draws item icons from polygons and colour maths, with an inventory grid that lifts, drags and frames each rarity; the sampler carries 15 of its 75 forms in all 12 materials. Kinetic UI draws widgets that move on springs; the sampler carries the button, the bar with its falling ghost, the menu and the tabs.

There is no sprite, no font resource and no texture page in the package; the type is drawn by the code too. One call, drawn_theme_apply, restyles all three in one of four themes. The demo room drives all three systems, and its Create event is the quickstart.

Because every name and parameter matches the paid product it came from, upgrading is a swap rather than a rewrite: delete that system's sampler scripts and import the full package. We checked that mechanically across 224 functions and 91 macros. The full versions are on the same page as links: Meridian, Trove and Kinetic UI.

Every test ran in a real Windows exe built by GameMaker's own compiler (runtime 2024.14.4.268): the in-engine suite, the Readme's own code in a blank project, and adversarial calls on every documented function. HTML5, mobile and YYC were not built.
