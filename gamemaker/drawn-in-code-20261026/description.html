Drawn in Code is a free GameMaker sampler (GameMaker 2024.14 and later, built and gated on runtime 2024.14.4.268), written in pure GML, with three working systems that draw their own art: a Meridian skill tree (15 motifs in 8 disciplines, the constellation layout), Trove item icons with an inventory grid (15 icon forms in 12 materials and 6 rarity tiers) and Kinetic UI widgets that move on springs (button, bar, menu and tabs). There are no sprites, no font resources and no texture pages: even the type is drawn by the code. You download a .yymps package with the raw GML, a Readme and a runnable demo room. It is free to use in unlimited games, commercial or free, and no attribution is required.

Each system is a trimmed copy of a paid product from the same studio, under that product's own names. Try the look in your own project first; if you want the rest, delete the sampler's scripts for that system and import the full package, and your code keeps working because every name and parameter matches (checked mechanically: 224 functions and 91 macros).

// Create
my_tree = mer_tree_make();
mer_tree_add(my_tree, "edge", { name: "EDGE", sigil: "THRUST", disc: 0, tier: MER_TIER_MAJOR, cost: 1, maxRank: 1, requires: [] });
my_grid = new TrvGrid(100, 100, 5, 3, 88, 12);
my_grid.set(0, new TrvItem("SUNBRAND", "SWORD", "GOLD", TRV_RARITY_LEGENDARY));
my_ui   = new KuiContext();
my_menu = new KuiMenu(["CONTINUE", "NEW GAME", "QUIT"]);

What is inside

  • Meridian, the skill tree: declare what a node is, what it costs and what it needs; the layout places every node from the prerequisite graph, and every node's mark is drawn from its motif in its discipline's colours. Buy, refund, ranks, keystones, a detail panel, pan and zoom. 15 of the full version's 60 motifs, all 8 disciplines, 1 of its 4 layouts.
  • Trove, the item icons: items are data (a form, a material, a rarity), and the icon is drawn from polygons and colour maths at any size. The inventory grid lifts on hover, drags and drops, and frames each rarity tier differently; the detail panel shows stats and value. 15 of the full version's 75 forms, all 12 materials, all 6 tiers.
  • Kinetic UI, the widgets: a menu whose highlight is a spring you can retarget mid-flight, health bars that leave a ghost when they fall, buttons and tabs. 4 of the full version's 8 widgets, all 4 themes.
  • One demo room that drives all three, one theme call (drawn_theme_apply) that restyles all three at once, and an in-engine self-test.

HTML5, mobile and YYC were not built.
