Pendant is out for GameMaker: any picture in your game becomes a spot-the-difference puzzle, hung twice in a drawn gallery, with the second copy changed in generated places.

You give it a sprite or a surface and a count. It reads the picture at a working size and makes the changes one place at a time: a small drawn object where the ground suits it (a fish only in water, a star only in a night sky, a key only on a stone wall or a table), a detail mirrored where the patch is uneven enough for the flip to show, a patch painted out through a soft edge, or an object with an edge of its own moved to a colour the picture already uses. Each change is measured before it is kept: if it does not move enough of the picture by a clear margin, it is undone and another place is tried. There are 51 objects; the RPG Maker MZ edition had 12.

The gallery is drawn by the package too: a damask wall, a picture rail with cords and brass hooks, gilt frames with beading and corner rosettes, picture lamps, and a brass plaque with the count, the clock, the misses and the hints. While the differences are made, a velvet drape hangs over the second painting, so a game does not freeze while the work is done a few milliseconds a frame. A find is ringed in red ink on both paintings, a hint lights a lamp glow over the next difference, and setting a puzzle aside marks every missed difference with a dashed gold ring. The result goes back to your game.

It is a port of our RPG Maker MZ plugin, and it is held to it: given the same picture, seed and count, the GameMaker core makes the same changes and the same second picture, byte for byte. Every test runs in a real exe built by GameMaker's own compiler (runtime 2024.14.4.268, VM, Windows); the shipped package is installed into a blank project and the Readme's own code run. HTML5, mobile and YYC exports were not built. Made with AI assistance: the code was written with AI, the gallery and the objects are drawn by that code, and the two demo paintings are AI-generated illustrations.
