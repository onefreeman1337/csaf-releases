Haversack is a grid inventory for GameMaker 2024.14 in pure GML: 55 drawn items with real footprints, 48 drawn containers, and a free Windows demo.

Items have shapes, not boxes. They lift, turn and drop with a ghost that marks exactly which cells are the problem. One commercial licence covers all your games.

What is inside

48 containers · 55 items · mouse, touch and gamepad · a demo room · raw GML source · no image files

  • Real footprints: any polyomino, declared in data, never taken from a sprite's size. Quarter turns keep the grabbed cell under the hand and the lamp upper left.
  • A drop that behaves: a refused drop springs back to the same cell and turn. Drop on one item to swap, on its own kind to stack.
  • A gamepad that walks the shapes: each press leaves the whole footprint, keeps its row past an L, and crosses to the next container at an edge.
  • Containers with rules: masks, dividers, weight limits that add up through nesting, your own accept function, scrolling. An item can be a bag.
  • Tidy: merges stacks and packs for the largest free space, and never loses an item.
  • Saves that survive your changes: rotation, nesting, stacks and your data return. Change a footprint after release and the item finds other room, or comes back to you.
  • It draws the whole screen: 8 kinds of container in 6 materials, cut foam to tufted velvet. Your own sprites go through the same footprints.

Each caption is the reason the package itself gave for that drop.

A few lines to a screen

// Create
hvs_starter_items();
my_bag = hvs_container({ w: 8, h: 5, kind: "attache", material: "hide" });
hvs_put(my_bag, hvs_item("rifle"), 0, 0);
my_desk = hvs_desk_create(); hvs_desk_add(my_desk, my_bag, 40, 40, { cell: 40 });
// Step
hvs_desk_step(my_desk);
// Draw GUI
hvs_desk_draw(my_desk);

Works with

GameMaker 2024.14 and later, built and tested on runtime 2024.14.4.268 (Windows, VM). HTML5, mobile and YYC were not built. Import with Tools > Import Local Package, then run rm_hvs_demo. Read the full documentation.
