Source Path Relinker - UE5 plugin is an Unreal Engine 5 plugin for Unreal Engine, paid.

The art folder moved, and now every Reimport says "Source file not found". Someone reorganised the texture library. The art moved to a NAS. A contractor delivered into a different tree than the last one. Every asset imported from the old location still records that old path, so Reimport fails on every machine that syncs, and it stays broken until somebody fixes it.

Unreal's answer is a modal file picker, in a details panel row, one asset at a time. ## This does the whole project, and it can prove it Anything can compare filenames. The reason this is a tool and not a script is that it knows the difference between a match it can prove and a match it is guessing at, and it tells you which one you are looking at.

When an asset is imported, the engine records the MD5 of the source file. That hash is still there, in the asset registry, long after the path went stale.

This indexes the folder you name, hashes the files whose extension a broken asset actually asked for, and matches on that recorded hash. ## Six answers, and the class is the product hash proven - exactly one file under your search root has the MD5 the engine recorded.
