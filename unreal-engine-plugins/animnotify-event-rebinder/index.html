AnimNotify Event Rebinder - UE5 plugin is an Unreal Engine 5 plugin for Unreal Engine, paid.

Its title or description names Unreal Engine 5.

You renamed a notify with Unreal's own Find and Replace. The animations took the new name. Every AnimNotify_ event in every Anim Blueprint kept the old one, and the engine looks that event up by name: when it is missing, nothing happens. No error, no warning. The footstep sound just stops. Epic closed the report as Won't Fix.

AnimNotify Event Rebinder finds every Anim Blueprint notify event that can never fire, proposes the rename that explains it, and carries a rename everywhere the name lives: the skeleton's notify list, every animation, every Anim Blueprint event and every mirror table row. Journalled, reversible, and runnable in CI. What it does Audit, writes nothing.

Every AnimNotify_ receiver in the folders you name, judged against what its skeleton lists and what its animations really carry: fires or never fires, with the number of nodes wired off each event that silently never run.

A table of every notify name per skeleton shows the names your animations and your skeleton list disagree on (the Animation Notifies window renames the list and not the animations), and the mirror table rows still pairing an old name. Proposes the rename that explains it.
