Brushfall is an editor plugin for Unreal Engine 5.8 on Windows that imports TrenchBroom and Quake.map files (Quake standard and Valve 220) as static meshes, convex collision, material instances and placed actors. Inside the download: the full C++ source (23 files, one editor module), a demo map with 57 brushes and 12 point entities, its eight textures and a WAD3 holding them, and a Readme.

The licence covers any number of your own projects, commercial included, with no royalty; everything it writes from your maps is yours to ship, and the demo map, textures and WAD are free to use in your games. The plugin itself is paid and stays in the editor. You block out the level in TrenchBroom because nothing builds a retro shooter faster.

Then it has to become an Unreal level: lit, collidable, textured, and updated every time you move a wall. Brushfall is that bridge, for Unreal Engine 5.8. What happens when you press Import Brushes merge. World brushes become one static mesh per cluster cell instead of one actor and one asset per brush. The demo map's 57 brushes come out as 8 meshes and 658 triangles. Collision is the brush, exactly.
