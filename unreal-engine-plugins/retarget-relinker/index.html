Retarget Relinker - UE5 plugin

Retarget Relinker - UE5 plugin is an Unreal Engine 5 plugin for Unreal Engine, paid.

You retargeted the animations. The new character has its own library now. And every gameplay Blueprint, Anim Blueprint default, DataTable row and soft reference in the new character's folder still plays the old character's animations. Unreal's two answers are both wrong for this: Epic's remap, EditorAnimUtils::ReplaceReferredAnimationsInBlueprint, takes a UAnimBlueprint*. It fixes Anim Blueprints only.

Replace References is global. It also redirects the old character, which has to keep its own animations. Retarget Relinker rewrites references only inside the folder you name, only to twins it can prove, and refuses anything that still belongs to the old character. What it does Builds a proven old-to-new mapping from the asset registry.

Each old animation asset is paired with the twin your naming rule predicts (-Prefix, -Suffix, -Replace). A pair is used only when the twin exists, is the same class, the old asset is on the old skeleton and the twin on the new one, and no other old asset predicts the same twin. No animation is loaded to decide it. Derives the skeletons instead of guessing.

A library on more than one skeleton is refused by name, with the switch to pass.
