Sound Cue Forge - UE5 plugin is an Unreal Engine 5 plugin for Unreal Engine, paid.

Its title or description names Unreal Engine 5.

You have a library of Sound Cues and MetaSounds is where the engine is going. There is no button that ports a cue: each one is rebuilt by hand, and the moment it is, every Blueprint, component and DataTable row still plays the old asset.

Sound Cue Forge reads every cue in the folders you name, decides cue by cue whether a faithful MetaSound equivalent exists, builds one for each cue that has it, refuses the rest and names the node that stopped it, points the assets that played the old cue at the new one, and journals every write so one command puts the project back. What it does Judges every cue.

PORTABLE (every node has a faithful MetaSound construction), APPROXIMATED (portable with a named difference you accept with a switch), or REFUSED (the node that stopped it, and why). Wave Player, Random, Mixer, Concatenator, Modulator, Looping, a fixed Delay and a root Attenuation port. Branch, Switch, Doppler, a random delay, mono mixed with stereo and every node outside that set are refused, never half-ported.

Names the differences you would otherwise find by ear. Unreal builds every Random node with Randomize Without Replacement switched on.
