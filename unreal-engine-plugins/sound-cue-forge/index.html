Sound Cue Forge is a plugin for Unreal Engine 5.8 that ports your Sound Cues to MetaSound Sources, relinks the assets that play them and journals every write. Use it in any number of your own projects, commercial or otherwise, with no royalty and no per seat fee.

What it does Judges every cue in the folders you name: PORTABLE, APPROXIMATED with a named difference you accept with a switch, or REFUSED with the node that stopped it. Wave Player, Random, Mixer, Concatenator, Modulator, Looping, a fixed Delay and a root Attenuation port. Branch, Switch, Doppler, a random delay and mono mixed with stereo are refused, never half ported.

Names the differences you would otherwise find by ear. A cue's Random node plays every input once before any repeats, while MetaSound's Random Get holds back at most half of them, so that cue reads APPROXIMATED and the finding says why.

Builds the MetaSound Source beside each cue as <Cue>_MS, reads the built document back, compares every node and connection before saving, then confirms the files through the asset registry. Relinks safely: Blueprint defaults, arrays, soft references, component properties, DataTable rows and Blueprint pin defaults.
