MetaSound Parameter Surgeon - UE5 plugin is an Unreal Engine 5 plugin for Unreal Engine, paid.

Its title or description names Unreal Engine 5.

You renamed one input on a MetaSound, Cutoff to CutoffHz. The MetaSound editor did exactly that. Nothing else followed. Every Set Float Parameter and its siblings, every Spawn Sound chain and every audio component's Default Parameters entry still sets Cutoff. Nothing errors, nothing warns, and the sound simply stops responding to them.

The name is a plain name on a pin, with no reference behind it, so neither Find in Blueprints nor the reference viewer can tell which Cutoff nodes belong to this MetaSound and which drive another sound that also has a Cutoff. MetaSound Parameter Surgeon decides that from the assets, carries the ones that belong to it, leaves the others alone by name, and refuses anything it cannot decide.

What it does Finds every place a Blueprint in your scope sets an audio parameter by name. The name pin of every setter the engine exposes (15 in 5.8, read from the engine's reflection data, including the four the audio component declares itself) and every Default Parameters entry on the audio components your Blueprints own. Decides which sound each one drives, from the asset alone.
