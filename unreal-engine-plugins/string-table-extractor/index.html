Its title or description names Unreal Engine 5.

Three hundred buttons, labels and tooltips were typed straight into the widgets. Now the game is being localized and the plan says String Tables. Unreal links one text at a time to a table entry (the flag beside a text field in the Details panel), and every translation you already paid for is orphaned the moment you do it by hand. Why by hand loses the translations.

A culture archive keeps a translation only while its namespace and key still match. A text moved into a String Table takes the table's namespace and a new key, so the next gather files it as a new, untranslated text and deletes the old entry once nothing gathers it (UE 5.8, GenerateGatherArchiveCommandlet.cpp, read from the engine source). What it does Finds the inline text.

Widget Blueprint widgets (text, tooltips, hint text), Blueprint class defaults and component templates, Blueprint graph pin defaults (Print Text, Format Text, Make Literal Text, any function input), Data Table rows and Data Assets, including nested structs, arrays and Map values. It opens only the packages the asset registry flags as carrying localizable text.
