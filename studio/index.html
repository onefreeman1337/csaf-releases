Core Systems Asset Factory

CSAF is a studio that builds engine tools, plugins, asset packs and games for people making games. This page describes what we make and how we make it.

How we work. Our products are made with AI, and every product says so in its own listing. Code ships as readable, commented source with no obfuscation, and each listing states what the product does and where its limits are.

What we make

Unity editor tools

Editor tools for Unity 6, written in C#. Each package carries a demo scene, named assembly definitions and readable, commented source.

Unreal Engine 5 plugins

Editor plugins for Unreal Engine 5 that change a project rather than report on it: migrators, relinkers and batch editors, shipped as C++ source.

RPG Maker MZ plugins

Plugins for RPG Maker MZ, shipped as readable JavaScript.

GameMaker assets

GML systems and visual libraries for GameMaker.

Tilesets and sprite packs

Pixel art tilesets with engine importers, and sprite packs of characters, creatures and effects.

Sound effects and game music

Procedurally synthesised sound effect packs and game music packs.

Games

Small games for desktop and the browser.

Documentation

Every product ships with a Readme covering setup and use. Unity packages submitted to the Unity Asset Store also carry an offline guide inside the package, with numbered sections, a table of contents, step by step setup and a script reference.

Support

Ask on the page you got the product from. Full source is included and commented, so most questions can be answered from the code itself.
