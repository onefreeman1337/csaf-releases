COMPOSITOR is a Game Boy typesetting puzzle with 40 formes: push four lead sorts into the composing stick in the right order and the line reads. The first 8 are free in your browser. What is inside 40 formes · 1 ROM of 32,768 bytes · 1 browser demo of 8 formes · Readme and licence A proved minimum on every forme.

Each one was searched exhaustively for its shortest sequence of pushes, and that number is BEST in the footer while you play. They run from 8 pushes to 18, in order. A forme picker on the title, so you can start at any forme and come back to the one you reached. There is no battery save. An ending. Set the fortieth line and an end card counts how many lines you set at the minimum, then credits. Undo and restart.

B takes back your latest 64 pushes and SELECT restarts the forme. Sound on the Game Boy's own four channels, all synthesis and no samples. The complete case. Every number is the proved minimum for that forme. The order is final A sort can only be pushed, never pulled, and there is no row beneath the composing stick to stand in.

Two sorts delivered in the wrong order can never be swapped, so a forme can be dead with everything still on screen.
