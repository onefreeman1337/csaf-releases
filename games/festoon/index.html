FESTOON is a game, paid, with a free browser demo on the store page.

String the festival lanterns through an old tree. Light every one with the fewest strings there are. Every fork of the tree holds a dark paper lantern. Press A on one to start a string, then run it along the limbs with the D-pad (small arrows show which direction takes which limb): every lantern it reaches lights up in that string's colour.

No lantern can hang on two strings, so a string can never run through a lantern that is already lit. Press A again to tie it off; B pulls it back one limb, and unties the last string if you change your mind. While a string is open, the frame round your lantern takes that string's colour. Light the whole tree with as few strings as you can.

The obvious plan, running the longest string you can first, misses par on most of the forty trees: the trick is where the strings meet at the forks. Every tree has a proved par For each of the forty trees, the fewest strings that can ever light it was worked out exactly on a computer before the cartridge was built. That is PAR on screen. Light it on par for GOLD, one over for SILVER, two over for BRONZE.

After you light a tree, press B to watch the proved par plan strung from a bare tree, string by string.
